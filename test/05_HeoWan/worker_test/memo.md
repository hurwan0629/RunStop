# 현재 목표

현재 알고리즘이 어떻게 짜여지며 어떤 입출력을 가질지 모르는 상황입니다.

알고리즘 팀에서 어느정도 큰 틀은 잡긴 했지만 아직 입출력의 형태가 구체화되지 않았습니다.

하지만 노드와 파이썬 사이의 통신이 되어야한다는 것이 확정되었기 때문에 

`json` 형식을 이용하기 위해
- Node: 일반객체 타입
- Python: dict 자료형

으로 통일시켜 직렬화하여 통신을 하는 방식으로 채택하기로 하였고

생각나는 문제점으로는 두가지의 입출력 타임, js의 DTO 타입과 python의 DTO 타입에 대해서 각각 정의를 해야하는 문제로 겹치는 DTO가 2개씩 만들어진다는 문제가 있습니다.

이에 대해서 일단 [알고리즘 명세서](./2026_08_29_알고리즘_명세_프레임.html) html 을 통해 json 및 알고리즘 구조 및 예외 등을 문서화할 수 있게 하였습니다.

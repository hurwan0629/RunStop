# RunStop

> 화장실·편의점·경사도·야간 인프라를 반영한 맞춤형 러닝 코스 추천 AI 서비스

## 📌 프로젝트 소개

**RunStop**은 사용자가 출발지와 원하는 러닝 조건을 입력하면
보행 경로와 여러 공공데이터를 활용하여 사용자에게 적합한 러닝 코스를 추천하는 서비스입니다.

단순히 최단 거리나 이동 경로만 제공하는 것이 아니라 다음과 같은 요소를 함께 고려하는 것을 목표로 합니다.

* 목표 거리
* 경사도
* 화장실
* 편의점
* 가로등 및 보안등
* 보행 가능 경로
* 야간 러닝 환경
* 사용자가 입력한 추가 조건

현재 프로젝트는 **기획 및 초기 설계 단계**이며, 세부 기능과 기술 스택은 개발 과정에서 구체화할 예정입니다.

---

## 🎯 프로젝트 목표

기존 러닝 서비스가 운동 기록이나 거리 중심으로 동작하는 것과 달리,

사용자의 상황과 선호 조건을 반영하여 **실제로 달리기 좋은 경로를 추천하는 것**을 목표로 합니다.

예를 들어 다음과 같은 요청을 처리할 수 있는 서비스를 구상하고 있습니다.

```text
5km 정도 뛰고 싶어요.

오르막은 적었으면 좋겠고
중간에 화장실이 있었으면 좋겠어요.

밤에 달릴 거라 가로등이 많은 길이면 좋겠어요.
```

서비스는 이러한 조건을 분석하여 적합한 러닝 코스 후보를 제공합니다.

---

## 🤖 AI 활용

현재 기획에서는 사용자의 자연어 입력을 분석하는 과정에 AI를 활용할 예정입니다.

예를 들어,

```text
"오르막이 별로 없고 밤에 안전하게 달릴 수 있는
5km 정도의 코스를 추천해줘."
```

와 같은 입력을 다음과 같은 구조화된 조건으로 변환하는 방식입니다.

```text
거리        : 약 5km
경사도      : 낮음
야간 조명   : 중요
안전시설    : 중요
```

AI가 추출한 결과는 바로 적용하지 않고
사용자가 한 번 확인하고 중요도나 조건을 수정할 수 있도록 하는 방향을 고려하고 있습니다.

AI의 구체적인 모델, LLM, 프롬프트 구조 및 적용 방식은 추후 결정합니다.

## 🔄 예상 서비스 흐름

```text
출발지 지정
    ↓
목적지 여부 설정
    ↓
러닝 조건 입력
    ↓
AI가 자연어 조건 분석
    ↓
조건 추출 결과 확인
    ↓
사용자가 중요도 / 조건 수정
    ↓
러닝 코스 후보 생성
    ↓
최대 3개의 후보 비교
    ↓
코스 선택
    ↓
러닝 시작
    ↓
러닝 종료
```

## 🗺️ 활용 예정 데이터

현재 기획안에서는 다음과 같은 데이터를 활용할 예정입니다.

| 데이터             | 활용 목적                |
| --------------- | -------------------- |
| 편의점             | 러닝 코스 주변 편의시설 탐색     |
| 공중화장실           | 코스 주변 화장실 위치 확인      |
| 가로등             | 야간 조명 환경 분석          |
| 보안등             | 야간 안전 인프라 분석         |
| 고도 / 등고선        | 도로 구간의 예상 경사도 계산     |
| 보행자전용도로         | 보행 가능한 경로 및 주변 시설 분석 |
| TMAP 보행자 경로 API | 실제 보행 가능한 경로 후보 생성   |

데이터의 실제 사용 범위와 전처리 방식은 추후 검토합니다.

## 🧩 예상 핵심 기능

현재까지 논의된 기능은 다음과 같습니다.

### 1. 출발지 설정

지도에서 사용자의 러닝 시작 위치를 지정합니다.

### 2. 러닝 조건 입력

사용자가 원하는 러닝 조건을 자연어 또는 입력 폼으로 입력합니다.

### 3. AI 조건 분석

사용자의 자연어 입력에서 거리, 경사도, 시설 선호도 등의 조건을 추출합니다.

### 4. 경로 후보 생성

보행 경로 API와 공공데이터를 이용하여 여러 러닝 코스 후보를 생성합니다.

### 5. 코스 평가 및 추천

각 코스가 사용자의 조건을 얼마나 만족하는지 평가합니다.

### 6. 코스 비교

최대 3개의 후보 코스를 제공하고 각 코스의 특징과 조건 충족 여부를 비교합니다.

## 🚧 예상 문제

### 자연어 조건 해석

```text
"적당히 짧은 길"
"오르막이 별로 없는 길"
```

과 같은 표현은 정확한 수치로 변환하기 어려울 수 있습니다.

따라서 AI의 분석 결과를 사용자에게 보여주고 직접 수정할 수 있도록 하는 방식을 고려합니다.

### 모든 조건을 만족하는 코스가 없는 경우

모든 조건을 만족하는 코스가 존재하지 않을 수 있습니다.

이 경우 조건 충족도가 높은 후보를 제공하고,

```text
거리       ✅
화장실     ✅
경사도     ✅
가로등     ❌
```

처럼 어떤 조건을 만족하지 못했는지 보여주는 방식을 고려합니다.

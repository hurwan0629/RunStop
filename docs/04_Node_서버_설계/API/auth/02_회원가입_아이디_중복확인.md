# 회원가입 아이디 중복확인

## 엔드포인트

- `POST /api/auth/check-login-id`

## 요청 스키마

```json
{
  "loginId": "string"
}
```

## 응답 스키마

```json
{
  "success": true,
  "data": {
    "available": true
  }
}
```

## 인증/인가

- `requireGuest`

## 검사하는 내용

- 요청 값 형식
- 로그인 아이디 중복 여부

## 조회하는 상태

- 로그인 아이디 `[users.login_id]`

## 저장/변경하는 상태

- 없음

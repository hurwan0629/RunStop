# 로그인

## 엔드포인트

- `POST /api/auth/login`

## 요청 스키마

```json
{
  "loginId": "string",
  "password": "string"
}
```

## 응답 스키마

```json
{
  "success": true,
  "data": {
    "accessToken": "string",
    "user": {
      "idx": 1,
      "nickname": "string",
      "role": "USER"
    }
  }
}
```

## 인증/인가

- `requireGuest`

## 검사하는 내용

- 요청 값 형식
- 로그인 아이디 존재 여부
- 비밀번호 일치 여부
- 탈퇴 사용자 여부
- 영구 정지 여부
- 기간 정지 여부
- 기간 정지 만료 여부

## 조회하는 상태

- 로그인 아이디 `[users.login_id]`
- 비밀번호 해시 `[users.password_hash]`
- 닉네임 `[users.nickname]`
- 권한 `[users.role]`
- 사용자 상태 `[users.status]`
- 정지 만료 시각 `[users.suspended_until]`

## 저장/변경하는 상태

- 마지막 로그인 시각 `[users.last_login_at]`
- 만료된 정지 상태 `[users.status]`
- 만료된 정지 시각 `[users.suspended_until]`
- 수정 시각 `[users.updated_at]`

# 회원가입 전화번호 인증번호 검증

## 엔드포인트

- `POST /api/auth/phone/verify`

## 요청 스키마

```json
{
  "verificationId": "uuid",
  "code": "123456"
}
```

## 응답 스키마

```json
{
  "success": true,
  "data": {
    "verified": true
  }
}
```

## 인증/인가

- `requireGuest`

## 검사하는 내용

- 요청 값 형식
- 인증 요청 존재 여부
- 인증 목적이 `SIGNUP`인지 여부
- 인증번호 만료 여부
- 시도 횟수 초과 여부
- 인증번호 일치 여부

## 조회하는 상태

- 전화번호 인증 요청 `verificationStore`

## 저장/변경하는 상태

- 시도 횟수 `verificationStore.record.attemptCount`
- 인증 완료 여부 `verificationStore.record.verified`
- 인증 완료 유효 시각 `verificationStore.record.verifiedUntil`

### 서버 객체 스키마

```json
{
  "verificationId": "uuid",
  "record": {
    "purpose": "SIGNUP",
    "phone": "01012345678",
    "codeHash": "sha256-string",
    "codeExpiresAt": "2026-09-01T12:03:00.000Z",
    "verified": true,
    "verifiedUntil": "2026-09-01T12:10:00.000Z",
    "attemptCount": 1
  }
}
```

# 비밀번호 재설정 전화번호 인증번호 발송

## 엔드포인트

- `POST /api/auth/password/phone/send`

## 요청 스키마

```json
{
  "loginId": "runner01",
  "phone": "01012345678"
}
```

## 응답 스키마

```json
{
  "success": true,
  "data": {
    "verificationId": "uuid",
    "expiresInSec": 180
  }
}
```

## 인증/인가

- `requireGuest`

## 검사하는 내용

- 요청 값 형식
- 로그인 아이디 존재 여부
- 로그인 아이디와 전화번호 일치 여부
- SMS 발송 가능 여부

## 조회하는 상태

- 로그인 아이디 `[users.login_id]`
- 전화번호 `[users.phone]`

## 저장/변경하는 상태

- 전화번호 인증 요청 `verificationStore`

### 서버 객체 스키마

```json
{
  "verificationId": "uuid",
  "record": {
    "purpose": "RESET_PASSWORD",
    "loginId": "runner01",
    "phone": "01012345678",
    "codeHash": "sha256-string",
    "codeExpiresAt": "2026-09-01T12:03:00.000Z",
    "verified": false,
    "attemptCount": 0
  }
}
```

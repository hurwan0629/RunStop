# 아이디 찾기 전화번호 인증번호 검증

## 엔드포인트

- `POST /api/auth/find-id/phone/verify`

## 요청 스키마

```json
{
  "verificationId": "uuid",
  "code": "123456"
}
```

## 응답 스키마

```json
{
  "success": true,
  "data": {
    "loginId": "runner01"
  }
}
```

## 인증/인가

- `requireGuest`

## 검사하는 내용

- 요청 값 형식
- 인증 목적이 `FIND_ID`인지 여부
- 인증번호 일치 여부
- 인증 전화번호와 연결된 사용자 존재 여부

## 조회하는 상태

- 전화번호 인증 요청 `verificationStore`
- 로그인 아이디 `[users.login_id]`
- 전화번호 `[users.phone]`

## 저장/변경하는 상태

- 시도 횟수 `verificationStore.record.attemptCount`
- 인증 완료 여부 `verificationStore.record.verified`
- 인증 완료 유효 시각 `verificationStore.record.verifiedUntil`

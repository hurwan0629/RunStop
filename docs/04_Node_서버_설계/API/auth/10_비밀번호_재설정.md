# 비밀번호 재설정

## 엔드포인트

- `POST /api/auth/password/reset`

## 요청 스키마

```json
{
  "verificationId": "uuid",
  "newPassword": "newPassword123"
}
```

## 응답 스키마

```json
{
  "success": true,
  "data": {
    "reset": true
  }
}
```

## 인증/인가

- `requireGuest`

## 검사하는 내용

- 요청 값 형식
- 전화번호 인증 완료 여부
- 인증 목적이 `RESET_PASSWORD`인지 여부
- 인증 요청과 연결된 사용자 존재 여부

## 조회하는 상태

- 전화번호 인증 요청 `verificationStore`
- 로그인 아이디 `[users.login_id]`

## 저장/변경하는 상태

- 비밀번호 해시 `[users.password_hash]`
- 수정 시각 `[users.updated_at]`
- 사용 완료 인증 요청 제거 `verificationStore`

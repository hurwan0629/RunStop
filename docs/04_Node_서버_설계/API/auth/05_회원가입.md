# 회원가입

## 엔드포인트

- `POST /api/auth/signup`

## 요청 스키마

```json
{
  "loginId": "runner01",
  "password": "password123",
  "nickname": "러너",
  "phone": "01012345678",
  "verificationId": "uuid",
  "profile": {
    "weightKg": 72.5,
    "heightCm": 175.3
  }
}
```

## 응답 스키마

```json
{
  "success": true,
  "data": {
    "accessToken": "string",
    "user": {
      "idx": 1,
      "nickname": "러너",
      "role": "USER"
    }
  }
}
```

## 인증/인가

- `requireGuest`

## 검사하는 내용

- 요청 값 형식
- 전화번호 인증 완료 여부
- 인증된 전화번호와 요청 전화번호 일치 여부
- 로그인 아이디 중복 여부
- 전화번호 중복 여부

## 조회하는 상태

- 전화번호 인증 요청 `verificationStore`
- 로그인 아이디 `[users.login_id]`
- 전화번호 `[users.phone]`

## 저장/변경하는 상태

- 로그인 아이디 `[users.login_id]`
- 비밀번호 해시 `[users.password_hash]`
- 닉네임 `[users.nickname]`
- 전화번호 `[users.phone]`
- 사용자 상태 `[users.status]`
- 권한 `[users.role]`
- 프로필 사용자 idx `[user_profiles.users_idx]`
- 몸무게 `[user_profiles.weight]`
- 키 `[user_profiles.height]`
- 사용 완료 인증 요청 제거 `verificationStore`

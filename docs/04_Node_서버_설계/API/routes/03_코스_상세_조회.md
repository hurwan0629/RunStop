# 코스 상세 조회

## 엔드포인트

- `GET /api/routes/:routeIdx`

## 요청 스키마

```json
{
  "params": {
    "routeIdx": 10
  }
}
```

## 응답 스키마

```json
{
  "success": true,
  "data": {
    "idx": 10,
    "name": "한강 5km 코스",
    "totalDistance": 5000,
    "totalAscent": 32.4,
    "slopeStd": 2.1,
    "isBookmarked": true,
    "path": [
      {
        "lat": 37.5665,
        "lng": 126.978
      },
      {
        "lat": 37.567,
        "lng": 126.979
      }
    ],
    "points": [
      {
        "sequence": 0,
        "pointType": "START",
        "lat": 37.5665,
        "lng": 126.978
      }
    ]
  }
}
```

## 인증/인가

- `authenticate`

## 검사하는 내용

- 코스 idx 형식
- 코스 존재 여부
- 사용자에게 조회 가능한 코스인지 여부

## 조회하는 상태

- 추천 코스 idx `[route_recommendations.idx]`
- 추천 코스명 `[route_recommendations.name]`
- 총 거리 `[route_recommendations.total_distance]`
- 총 상승 고도 `[route_recommendations.total_ascent]`
- 경사 표준편차 `[route_recommendations.slope_std]`
- 전체 경로 `[route_recommendations.route]`
- 주요 지점 순서 `[route_points.sequence]`
- 주요 지점 타입 `[route_points.point_type]`
- 주요 지점 좌표 `[route_points.point]`
- 즐겨찾기 여부 `[route_bookmarks.route_recommendations_idx]`

## 저장/변경하는 상태

- 없음

## 구현 메모

- `path`는 `route_recommendations.route` LineString을 좌표 배열로 변환한 전체 경로입니다.
- `points`는 `route_points` 테이블의 START/WAYPOINT/END 주요 지점입니다.
- 상세 응답의 feature 요소는 현재 화면/Worker 임시 계약입니다. Python 추천 알고리즘과 지도 화면 요구사항이 확정되면 확장될 수 있습니다.

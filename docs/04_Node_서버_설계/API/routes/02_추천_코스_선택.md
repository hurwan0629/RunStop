# 추천 코스 선택

## 엔드포인트

- `POST /api/routes/:requestIdx/select`

## 요청 스키마

```json
{
  "params": {
    "requestIdx": 1
  },
  "recommendationIdx": 10
}
```

## 응답 스키마

```json
{
  "success": true,
  "data": {
    "requestIdx": 1,
    "selectedRecommendationIdx": 10
  }
}
```

## 인증/인가

- `authenticate`

## 검사하는 내용

- 추천 요청 소유자 일치 여부
- 추천 후보가 해당 요청에서 생성된 값인지 여부
- 이미 선택된 요청인지 여부

## 조회하는 상태

- 추천 요청 idx `[route_requests.idx]`
- 추천 요청 사용자 idx `[route_requests.users_idx]`
- 선택된 추천 idx `[route_requests.selected_recommendations_idx]`
- 추천 후보 idx `[route_recommendations.idx]`
- 추천 후보의 요청 idx `[route_recommendations.route_requests_idx]`

## 저장/변경하는 상태

- 선택된 추천 idx `[route_requests.selected_recommendations_idx]`

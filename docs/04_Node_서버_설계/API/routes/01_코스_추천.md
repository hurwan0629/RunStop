# 코스 추천

## 엔드포인트

- `POST /api/routes/recommend`

## 요청 스키마

```ts
{
  prompt?: string;
  routeType: "LOOP" | "ROUND_TRIP" | "ONE_WAY";
  startPoint: { lat: number; lng: number; sequence?: number };
  waypoints?: Array<{ lat: number; lng: number; sequence?: number }>;
  endPoint?: { lat: number; lng: number; sequence?: number };
  elementConditions: {
    targetDistance: number;
    maxSlope?: number;
    facilityCount?: number;
    weights?: Record<string, number>;
    requirements?: Record<string, boolean | number>;
  };
}
```

## elementConditions 세부 규칙

- `targetDistance`는 필수이며 meter 단위의 양수입니다.
- `weights` 값은 `1~5` 범위로 정규화됩니다.
- `weights` 허용 키는 `distance`, `elevation`, `safety`, `night`, `nature`, `park`, `surface`, `flow`, `overlap`, `toilet`, `store`입니다.
- `requirements` boolean 허용 키는 `toilet`, `store`, `park`, `no_stairs`입니다.
- `requirements` number 허용 키는 `max_slope_pct`, `max_slope`, `maxSlope`입니다.
- 허용되지 않은 `weights`, `requirements` 키는 에러를 내지 않고 제거됩니다.
- `prompt`가 있으면 LLM이 `weights`, `requirements` 후보를 만들고, 같은 키가 있으면 사용자 요청값이 우선합니다.

## 요청 예시

```json
{
  "prompt": "5km 정도로 경사가 심하지 않고 편의시설이 있는 코스로 추천해줘",
  "routeType": "LOOP",
  "startPoint": {
    "lat": 37.5665,
    "lng": 126.978
  },
  "waypoints": [
    {
      "lat": 37.57,
      "lng": 126.985
    }
  ],
  "elementConditions": {
    "targetDistance": 5000,
    "weights": {
      "distance": 5,
      "elevation": 4,
      "toilet": 5,
      "store": 2,
      "park": 3,
      "night": 5
    },
    "requirements": {
      "toilet": true,
      "no_stairs": true,
      "max_slope_pct": 8
    }
  }
}
```

## 응답 스키마

```ts
{
  success: true;
  data: {
    requestIdx: number;
    recommendations: Array<{
      idx: number;
      name: string;
      score: number | null;
      totalDistance: number | null;
      totalAscent: number | null;
      slopeStd: number | null;
    }>;
  };
}
```

## 처리 흐름

- `routeRequestSchema`로 요청을 검증하고 `weights`, `requirements` 허용 키를 정리합니다.
- `prompt`가 있으면 LLM adapter가 조건 후보를 만들고, 사용자 입력 조건과 병합합니다.
- Node는 routing-worker의 `/routes/recommend`로 `WorkerRouteRequestDTO`를 전달합니다.
- worker 응답은 DB transaction 안에서 `route_requests`, `route_request_points`, `route_recommendations`, `route_points`에 저장됩니다.

# 코스 추천

## 엔드포인트

- `POST /api/routes/recommend`

## 요청 스키마

```json
{
  "prompt": "한강 근처 5km 러닝 코스",
  "startPoint": {
    "lat": 37.5665,
    "lng": 126.978
  },
  "elementConditions": {
    "targetDistance": 5000,
    "maxSlope": 8,
    "facilityCount": 2
  }
}
```

## 응답 스키마

```json
{
  "success": true,
  "data": {
    "requestIdx": 1,
    "recommendations": [
      {
        "idx": 10,
        "name": "한강 5km 코스",
        "score": 91.5,
        "totalDistance": 5000,
        "totalAscent": 32.4,
        "slopeStd": 2.1
      }
    ]
  }
}
```

## 인증/인가

- `authenticate`

## 검사하는 내용

- 출발 좌표 값 범위
- 거리, 경사, 시설 조건 형식
- Worker 또는 TMap 호출 가능 여부
- 추천 결과가 저장 가능한 형식인지 여부

## 조회하는 상태

- 사용자 idx `[users.idx]`
- 사용자 프로필 설정 `[user_profiles.running_settings]`

## 저장/변경하는 상태

- 추천 요청 사용자 idx `[route_requests.users_idx]`
- 사용자 입력 프롬프트 `[route_requests.prompt]`
- 추천 조건 `[route_requests.element_conditions]`
- 요청 지점 순서 `[route_request_points.sequence]`
- 요청 지점 타입 `[route_request_points.point_type]`
- 요청 지점 좌표 `[route_request_points.point]`
- 추천 코스명 `[route_recommendations.name]`
- 추천 점수 `[route_recommendations.score]`
- 추천 점수 상세 `[route_recommendations.feature_scores]`
- 추천 실제 값 `[route_recommendations.feature_values]`
- 총 거리 `[route_recommendations.total_distance]`
- 총 상승 고도 `[route_recommendations.total_ascent]`
- 경사 표준편차 `[route_recommendations.slope_std]`
- 전체 경로 `[route_recommendations.route]`
- 주요 지점 `[route_points.point]`

# 코스 추천

## 엔드포인트

- `POST /api/routes/recommend`

## 요청 스키마

```json
{
  "prompt": "한강 근처 5km 러닝 코스",
  "startPoint": {
    "lat": 37.5665,
    "lng": 126.978
  },
  "waypoints": [
    {
      "lat": 37.5651,
      "lng": 126.981
    }
  ],
  "endPoint": {
    "lat": 37.57,
    "lng": 126.982
  },
  "elementConditions": {
    "targetDistance": 5000,
    "maxSlope": 8,
    "facilityCount": 2
  }
}
```

## 응답 스키마

```json
{
  "success": true,
  "data": {
    "requestIdx": 1,
    "recommendations": [
      {
        "idx": 10,
        "name": "한강 5km 코스",
        "score": 91.5,
        "totalDistance": 5000,
        "totalAscent": 32.4,
        "slopeStd": 2.1
      }
    ]
  }
}
```

## 인증/인가

- `authenticate`

## 검사하는 내용

- 출발 좌표 값 범위
- 경유지 좌표 값 범위
- 도착 좌표 값 범위
- 도착 좌표가 없으면 출발 좌표를 도착 좌표로 사용하는 왕복형 요청 여부
- 거리, 경사, 시설 조건 형식
- Worker 또는 TMap 호출 가능 여부
- 추천 결과가 저장 가능한 형식인지 여부

## 조회하는 상태

- 사용자 idx `[users.idx]`
- 사용자 프로필 설정 `[user_profiles.running_settings]`

## 저장/변경하는 상태

- 추천 요청 사용자 idx `[route_requests.users_idx]`
- 사용자 입력 프롬프트 `[route_requests.prompt]`
- 추천 조건 `[route_requests.element_conditions]`
- 요청 지점 순서 `[route_request_points.sequence]`
- 요청 지점 타입 `[route_request_points.point_type]`
- 요청 지점 좌표 `[route_request_points.point]`
- 추천 코스명 `[route_recommendations.name]`
- 추천 점수 `[route_recommendations.score]`
- 추천 점수 상세 `[route_recommendations.feature_scores]`
- 추천 실제 값 `[route_recommendations.feature_values]`
- 총 거리 `[route_recommendations.total_distance]`
- 총 상승 고도 `[route_recommendations.total_ascent]`
- 경사 표준편차 `[route_recommendations.slope_std]`
- 전체 경로 `[route_recommendations.route]`
- 주요 지점 `[route_points.point]`

## 구현 메모

- Worker 호출이 정상 응답을 반환한 뒤 DB transaction을 시작합니다.
- Node는 Worker 호출 전에 요청 좌표를 `startPoint`, `waypoints`, `endPoint`로 정리합니다.
- `waypoints`는 0개 이상 받을 수 있으며, 저장 시 `WAYPOINT` 타입으로 순서대로 기록합니다.
- `endPoint`가 없으면 `startPoint`를 `END`로 한 번 더 저장하고 Worker에는 `isRoundTrip: true`로 전달합니다.
- 요청 지점 저장 순서는 `START(sequence=0) -> WAYPOINT(sequence=1..n) -> END(sequence=n+1)`입니다.
- transaction 안에서 `route_requests`, `route_request_points`, `route_recommendations`, `route_points`를 한 번에 저장합니다.
- `elementConditions`는 현재 Node-Worker 임시 계약입니다. Python 추천 알고리즘의 입력 feature가 확정되면 필드명이 변경되거나 확장될 수 있습니다.
- DB에는 `route_requests.element_conditions`를 jsonb로 저장하므로 조건 구조 확장은 DB 컬럼 변경 없이 가능합니다.

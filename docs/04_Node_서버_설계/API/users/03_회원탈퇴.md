# 회원탈퇴

## 엔드포인트

- `DELETE /api/users/me`

## 요청 스키마

```json
{}
```

## 응답 스키마

```json
{
  "success": true,
  "data": {
    "withdrawn": true
  }
}
```

## 인증/인가

- `authenticate`

## 검사하는 내용

- 액세스 토큰 유효 여부
- 사용자 존재 여부
- 이미 탈퇴한 사용자인지 여부
- 탈퇴 업데이트가 실제로 반영되었는지 여부

## 조회하는 상태

- 사용자 idx `[users.idx]`
- 사용자 상태 `[users.status]`

## 저장/변경하는 상태

- 사용자 상태 `[users.status]`
- 탈퇴 시각 `[users.withdrawn_at]`
- 수정 시각 `[users.updated_at]`
- 로그인 아이디 익명화 `[users.login_id]`
- 전화번호 제거 `[users.phone]`
- 비밀번호 해시 무효화 `[users.password_hash]`

## 메모

- 사용자와 연결된 러닝, 목표, 즐겨찾기, 문의 기록은 물리 삭제하지 않습니다.
- `login_id`는 unique 제약 재사용을 위해 `withdraw_${userIdx}_${randomUUID().replaceAll("-", "").slice(0, 12)}` 형태로 익명화합니다.
- `phone`은 unique 제약 재사용을 위해 `NULL`로 변경합니다.
- `password_hash`는 기존 비밀번호로 로그인할 수 없도록 무작위 문자열의 bcrypt 해시로 변경합니다.

# 내 정보 수정

## 엔드포인트

- `PATCH /api/users/me`

## 요청 스키마

```json
{
  "nickname": "러너",
  "weightKg": 72.5,
  "heightCm": 175.3,
  // 파이썬 프로젝트 완료 후 제대로 채워질 부분입니다. (현재는 임시)
  "runningSettings": {
    "targetDistanceM": 5000,
    "maxSlopePercent": 8,
    "preferredSurface": "park"
  }
}
```

## 응답 스키마

```json
{
  "success": true,
  "data": {
    "user": {
      "idx": 1,
      "nickname": "러너"
    },
    "profile": {
      "weightKg": 72.5,
      "heightCm": 175.3,
      // 파이썬 프로젝트 완료 후 제대로 채워질 부분입니다. (현재는 임시)
      "runningSettings": {
        "targetDistanceM": 5000,
        "maxSlopePercent": 8,
        "preferredSurface": "park"
      },
      "profileImageUrl": null
    }
  }
}
```

## 인증/인가

- `authenticate`

## 검사하는 내용

- 액세스 토큰 유효 여부
- 수정할 값이 하나 이상 있는지 여부
- 닉네임 길이
- 몸무게 양수 여부
- 키 양수 여부
- 러닝 설정이 JSON 객체인지 여부
- 사용자 존재 여부
- 사용자 프로필 존재 여부

## 조회하는 상태

- 사용자 idx `[users.idx]`
- 사용자 상태 `[users.status]`
- 프로필 사용자 idx `[user_profiles.users_idx]`

## 저장/변경하는 상태

- 닉네임 `[users.nickname]`
- 수정 시각 `[users.updated_at]`
- 몸무게 `[user_profiles.weight]`
- 키 `[user_profiles.height]`
- 러닝 설정 `[user_profiles.running_settings]`

## 메모

- `phone`은 전화번호 인증 흐름이 필요하므로 이 API에서 수정하지 않습니다.
- `profileImageUrl`은 현재 DB 컬럼이 없으므로 이 API에서 수정하지 않습니다.
- `runningSettings`는 추후 Python 추천/분석 모듈과 결합할 수 있도록 JSON 객체 형태를 유지합니다.

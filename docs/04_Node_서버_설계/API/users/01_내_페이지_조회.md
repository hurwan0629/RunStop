## 인증/인가

- `authenticate`

## 검사하는 내용

- 액세스 토큰 유효 여부
- 사용자 존재 여부
- 사용자 상태가 요청 가능한 상태인지 여부
- 진행 중인 목표가 없으면 `currentGoal`은 `null`로 반환
- 러닝 집계는 `IN_PROGRESS` 상태를 제외

## 조회하는 상태

- 사용자 idx `[users.idx]`
- 로그인 아이디 `[users.login_id]`
- 닉네임 `[users.nickname]`
- 권한 `[users.role]`
- 경험치 `[users.total_exp]`
- 프로필 사용자 idx `[user_profiles.users_idx]`
- 몸무게 `[user_profiles.weight]`
- 키 `[user_profiles.height]`
- 러닝 설정 `[user_profiles.running_settings]`
- 현재 목표 idx `[running_goals.idx]`
- 목표 타입 `[running_goals.goal_type]`
- 목표 거리 `[running_goals.target_distance]`
- 목표 상태 `[running_goals.status]`
- 목표 시작일 `[running_goals.start_date]`
- 목표 종료일 `[running_goals.end_date]`
- 목표 시작일 이후 오늘까지 달린 거리 `[running_sessions.distance]`
- 러닝 기록 총 횟수 `[running_sessions.idx]`
- 러닝 총 거리 `[running_sessions.distance]`
- 최고 페이스 `[running_sessions.average_pace]`
- 코스 즐겨찾기 수 `[route_bookmarks.idx]`

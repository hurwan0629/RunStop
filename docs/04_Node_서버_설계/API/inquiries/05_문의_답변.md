# 문의 답변

## 엔드포인트

- `POST /api/inquiries/:inquiryIdx/answer`

## 요청 스키마

```json
{
  "params": {
    "inquiryIdx": 1
  },
  "body": {
    "answer": "답변 내용",
    "memo": "관리자 내부 메모"
  }
}
```

## 응답 스키마

```json
{
  "success": true,
  "data": {
    "idx": 1,
    "status": "ANSWERED",
    "answererIdx": 2,
    "answeredAt": "2026-09-01T13:00:00.000Z"
  }
}
```

## 인증/인가

- `authenticate`
- `requireAdmin`

## 검사하는 내용

- 관리자 권한 여부
- 문의 idx 형식
- 답변 내용 길이
- 이미 답변된 문의인지 여부
- 답변 저장 시 문의 상태는 `ANSWERED`로 변경

## 조회하는 상태

- 문의 idx `[inquiries.idx]`
- 현재 상태 `[inquiries.status]`
- 기존 답변 `[inquiries.answer]`

## 저장/변경하는 상태

- 답변 `[inquiries.answer]`
- 답변자 idx `[inquiries.answerer_idx]`
- 관리자 메모 `[inquiries.memo]`
- 문의 상태 `[inquiries.status]`
- 답변 시각 `[inquiries.answered_at]`

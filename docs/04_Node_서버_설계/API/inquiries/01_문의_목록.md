# 문의 목록

## 엔드포인트

- `GET /api/inquiries`

## 요청 스키마

```json
{
  "query": {
    "page": 1,
    "limit": 20,
    "status": "PENDING"
  }
}
```

## 응답 스키마

```json
{
  "success": true,
  "data": {
    "items": [
      {
        "idx": 1,
        "title": "문의 제목",
        "status": "PENDING",
        "createdAt": "2026-09-01T12:00:00.000Z"
      }
    ],
    "page": 1,
    "limit": 20
  }
}
```

## 인증/인가

- `authenticate`

## 검사하는 내용

- 페이지네이션 값 범위
- 문의 상태 필터 값
- 일반 사용자는 본인 문의만 조회하는지 여부
- 관리자는 전체 문의 조회가 가능한지 여부

## 조회하는 상태

- 문의 idx `[inquiries.idx]`
- 사용자 idx `[inquiries.users_idx]`
- 제목 `[inquiries.title]`
- 상태 `[inquiries.status]`
- 생성 시각 `[inquiries.created_at]`

## 저장/변경하는 상태

- 없음

# 문의 상태 변경

## 엔드포인트

- `PATCH /api/inquiries/:inquiryIdx/status`

## 요청 스키마

```json
{
  "params": {
    "inquiryIdx": 1
  },
  "body": {
    "status": "IN_PROGRESS"
  }
}
```

## 응답 스키마

```json
{
  "success": true,
  "data": {
    "idx": 1,
    "status": "IN_PROGRESS"
  }
}
```

## 인증/인가

- `authenticate`
- `requireAdmin`

## 검사하는 내용

- 관리자 권한 여부
- 문의 idx 형식
- 문의 존재 여부
- 변경 가능한 상태 전이인지 여부
- 현재 DB 상태 enum은 `PENDING`, `IN_PROGRESS`, `ANSWERED`

## 조회하는 상태

- 문의 idx `[inquiries.idx]`
- 현재 상태 `[inquiries.status]`

## 저장/변경하는 상태

- 문의 상태 `[inquiries.status]`

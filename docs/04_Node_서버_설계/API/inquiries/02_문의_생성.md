# 문의 생성

## 엔드포인트

- `POST /api/inquiries`

## 요청 스키마

```json
{
  "title": "문의 제목",
  "content": "문의 내용"
}
```

## 응답 스키마

```json
{
  "success": true,
  "data": {
    "idx": 1,
    "title": "문의 제목",
    "content": "문의 내용",
    "status": "PENDING",
    "answer": null,
    "createdAt": "2026-09-01T12:00:00.000Z",
    "answeredAt": null
  }
}
```

## 인증/인가

- `authenticate`

## 검사하는 내용

- 제목 길이
- 내용 길이
- 문의 생성 가능한 사용자 상태인지 여부

## 조회하는 상태

- 사용자 idx `[users.idx]`
- 사용자 상태 `[users.status]`

## 저장/변경하는 상태

- 사용자 idx `[inquiries.users_idx]`
- 제목 `[inquiries.title]`
- 내용 `[inquiries.content]`
- 상태 `[inquiries.status]`
- 생성 시각 `[inquiries.created_at]`

# 문의 상세 조회

## 엔드포인트

- `GET /api/inquiries/:inquiryIdx`

## 요청 스키마

```json
{
  "params": {
    "inquiryIdx": 1
  }
}
```

## 응답 스키마

```json
{
  "success": true,
  "data": {
    "idx": 1,
    "title": "문의 제목",
    "content": "문의 내용",
    "status": "ANSWERED",
    "answer": "답변 내용",
    "answeredAt": "2026-09-01T13:00:00.000Z"
  }
}
```

## 인증/인가

- `authenticate`

## 검사하는 내용

- 문의 idx 형식
- 일반 사용자는 본인 문의만 조회하는지 여부
- 관리자는 전체 문의 조회가 가능한지 여부

## 조회하는 상태

- 문의 idx `[inquiries.idx]`
- 사용자 idx `[inquiries.users_idx]`
- 제목 `[inquiries.title]`
- 내용 `[inquiries.content]`
- 상태 `[inquiries.status]`
- 답변 `[inquiries.answer]`
- 답변자 idx `[inquiries.answerer_idx]`
- 답변 시각 `[inquiries.answered_at]`

## 저장/변경하는 상태

- 없음

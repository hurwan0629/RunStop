# 목표 중지

## 엔드포인트

- `POST /api/goals/:goalIdx/stop`

## 요청 스키마

```json
{
  "params": {
    "goalIdx": 1
  }
}
```

## 응답 스키마

```json
{
  "success": true,
  "data": {
    "idx": 1,
    "status": "STOPPED",
    "finishedAt": "2026-09-01T12:00:00.000Z"
  }
}
```

## 인증/인가

- `authenticate`

## 검사하는 내용

- 목표 idx 형식
- 목표 소유자 일치 여부
- 목표가 중지 가능한 상태인지 여부

## 조회하는 상태

- 목표 idx `[running_goals.idx]`
- 사용자 idx `[running_goals.users_idx]`
- 목표 상태 `[running_goals.status]`

## 저장/변경하는 상태

- 목표 상태 `[running_goals.status]`
- 목표 종료 시각 `[running_goals.finished_at]`

# 목표 생성

## 엔드포인트

- `POST /api/goals`

## 요청 스키마

```json
{
  "goalType": "WEEKLY",
  "targetDistance": 20000,
  "startDate": "2026-09-01",
  "endDate": "2026-09-07"
}
```

## 응답 스키마

```json
{
  "success": true,
  "data": {
    "idx": 1,
    "goalType": "WEEKLY",
    "targetDistance": 20000,
    "status": "ACTIVE"
  }
}
```

## 인증/인가

- `authenticate`

## 검사하는 내용

- 목표 종류 값
- 목표 거리 양수 여부
- 시작일과 종료일 순서
- 동일 기간의 활성 목표 존재 여부

## 조회하는 상태

- 사용자 idx `[running_goals.users_idx]`
- 목표 상태 `[running_goals.status]`
- 목표 시작일 `[running_goals.start_date]`
- 목표 종료일 `[running_goals.end_date]`

## 저장/변경하는 상태

- 사용자 idx `[running_goals.users_idx]`
- 목표 종류 `[running_goals.goal_type]`
- 목표 거리 `[running_goals.target_distance]`
- 목표 상태 `[running_goals.status]`
- 시작일 `[running_goals.start_date]`
- 종료일 `[running_goals.end_date]`
- 생성 시각 `[running_goals.created_at]`

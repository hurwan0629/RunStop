# 현재 목표 조회

## 엔드포인트

- `GET /api/goals/current`

## 요청 스키마

```json
{}
```

## 응답 스키마

```json
{
  "success": true,
  "data": {
    "goal": {
      "idx": 1,
      "goalType": "WEEKLY",
      "targetDistance": 20000,
      "status": "ACTIVE",
      "startDate": "2026-09-01",
      "endDate": "2026-09-07"
    },
    "progress": {
      "distance": 5000,
      "rate": 25
    }
  }
}
```

## 인증/인가

- `authenticate`

## 검사하는 내용

- 액세스 토큰 유효 여부
- 만료된 목표 상태 갱신 필요 여부

## 조회하는 상태

- 목표 idx `[running_goals.idx]`
- 사용자 idx `[running_goals.users_idx]`
- 목표 종류 `[running_goals.goal_type]`
- 목표 거리 `[running_goals.target_distance]`
- 목표 상태 `[running_goals.status]`
- 시작일 `[running_goals.start_date]`
- 종료일 `[running_goals.end_date]`
- 러닝 거리 `[running_sessions.distance]`
- 러닝 시작 시각 `[running_sessions.started_at]`

## 저장/변경하는 상태

- 만료된 목표 상태 `[running_goals.status]`
- 목표 종료 시각 `[running_goals.finished_at]`

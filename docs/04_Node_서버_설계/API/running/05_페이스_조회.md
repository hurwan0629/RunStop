# 페이스 조회

## 엔드포인트

- `GET /api/running-sessions/:sessionIdx/pace`

## 요청 스키마

```json
{
  "params": {
    "sessionIdx": 1
  }
}
```

## 응답 스키마

```json
{
  "success": true,
  "data": {
    "sessionIdx": 1,
    "averagePace": 360,
    "segments": [
      {
        "distanceFrom": 0,
        "distanceTo": 1000,
        "pace": 355
      }
    ]
  }
}
```

## 인증/인가

- `authenticate`

## 검사하는 내용

- 세션 idx 형식
- 세션 소유자 일치 여부
- 페이스 계산에 충분한 트랙포인트 존재 여부

## 조회하는 상태

- 세션 idx `[running_sessions.idx]`
- 사용자 idx `[running_sessions.users_idx]`
- 평균 페이스 `[running_sessions.average_pace]`
- 트랙포인트 좌표 `[running_trackpoints.point]`
- 트랙포인트 기록 시각 `[running_trackpoints.recorded_at]`

## 저장/변경하는 상태

- 없음

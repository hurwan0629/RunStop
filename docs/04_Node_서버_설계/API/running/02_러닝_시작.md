# 러닝 시작

## 엔드포인트

- `POST /api/running-sessions/start`

## 요청 스키마

```json
{
  "routeRecommendationIdx": 10,
  "startedAt": "2026-09-01T10:00:00.000Z"
}
```

## 응답 스키마

```json
{
  "success": true,
  "data": {
    "sessionIdx": 1,
    "status": "IN_PROGRESS"
  }
}
```

## 인증/인가

- `authenticate`

## 검사하는 내용

- 선택한 코스 존재 여부
- 진행 중인 세션 중복 여부
- 시작 시각 형식

## 조회하는 상태

- 진행 중 상태 `[running_sessions.status]`
- 사용자 idx `[running_sessions.users_idx]`
- 코스 idx `[route_recommendations.idx]`

## 저장/변경하는 상태

- 사용자 idx `[running_sessions.users_idx]`
- 추천 코스 idx `[running_sessions.route_recommendations_idx]`
- 상태 `[running_sessions.status]`
- 시작 시각 `[running_sessions.started_at]`

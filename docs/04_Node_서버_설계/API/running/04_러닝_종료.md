# 러닝 종료

## 엔드포인트

- `POST /api/running-sessions/:sessionIdx/finish`

## 요청 스키마

```json
{
  "finishedAt": "2026-09-01T10:30:00.000Z"
}
```

## 응답 스키마

```json
{
  "success": true,
  "data": {
    "sessionIdx": 1,
    "status": "COMPLETED",
    "distance": 5000,
    "averagePace": 360
  }
}
```

## 인증/인가

- `authenticate`

## 검사하는 내용

- 세션 idx 형식
- 세션 소유자 일치 여부
- 세션이 `IN_PROGRESS`인지 여부
- 저장된 트랙포인트로 거리 계산 가능한지 여부
- 거리 계산에 사용하는 트랙포인트 정확도 조건 `(accuracy IS NULL OR accuracy <= 50)`
- 종료 시각이 시작 시각 이후인지 여부

## 조회하는 상태

- 세션 idx `[running_sessions.idx]`
- 사용자 idx `[running_sessions.users_idx]`
- 세션 상태 `[running_sessions.status]`
- 시작 시각 `[running_sessions.started_at]`
- 트랙포인트 좌표 `[running_trackpoints.point]`
- 트랙포인트 기록 시각 `[running_trackpoints.recorded_at]`
- 트랙포인트 정확도 `[running_trackpoints.accuracy]`

## 저장/변경하는 상태

- 세션 상태 `[running_sessions.status]`
- 종료 시각 `[running_sessions.finished_at]`
- 실제 거리 `[running_sessions.distance]`
- 평균 페이스 `[running_sessions.average_pace]`

## 구현 메모

- 정상 종료 API는 서버가 `COMPLETED` 상태를 고정 저장합니다.
- 실제 거리는 PostGIS에서 `ST_MakeLine(point ORDER BY recorded_at, idx)`를 만든 뒤 `ST_Transform(..., 5179)`와 `ST_Length`로 계산합니다.
- 거리 계산에는 `accuracy IS NULL OR accuracy <= 50` 조건을 통과한 트랙포인트만 사용합니다.
- `STOPPED`, `FAILED`는 별도 API 또는 추후 확장 흐름에서 다룹니다.

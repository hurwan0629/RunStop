# 러닝 세션 목록

## 엔드포인트

- `GET /api/running-sessions`

## 요청 스키마

```json
{
  "query": {
    "page": 1,
    "limit": 20,
    "from": "2026-09-01",
    "to": "2026-09-30"
  }
}
```

## 응답 스키마

```json
{
  "success": true,
  "data": {
    "items": [
      {
        "idx": 1,
        "status": "COMPLETED",
        "startedAt": "2026-09-01T10:00:00.000Z",
        "finishedAt": "2026-09-01T10:30:00.000Z",
        "distance": 5000,
        "averagePace": 360
      }
    ],
    "page": 1,
    "limit": 20
  }
}
```

## 인증/인가

- `authenticate`

## 검사하는 내용

- 페이지네이션 값 범위
- 조회 기간 형식
- 조회 시작일이 종료일보다 늦지 않은지 여부
- 본인 세션만 조회하는지 여부

## 조회하는 상태

- 러닝 세션 idx `[running_sessions.idx]`
- 사용자 idx `[running_sessions.users_idx]`
- 상태 `[running_sessions.status]`
- 시작 시각 `[running_sessions.started_at]`
- 종료 시각 `[running_sessions.finished_at]`
- 거리 `[running_sessions.distance]`
- 평균 페이스 `[running_sessions.average_pace]`

## 저장/변경하는 상태

- 없음

## 구현 메모

- 러닝 기록 목록은 `IN_PROGRESS` 상태를 제외하고 조회합니다.
- 정렬은 `started_at DESC, idx DESC` 기준입니다.

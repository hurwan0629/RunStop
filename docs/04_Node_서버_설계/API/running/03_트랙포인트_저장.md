# 트랙포인트 저장

## 엔드포인트

- `POST /api/running-sessions/trackpoints`

## 요청 스키마

```json
{
  "sessionIdx": 1,
  "trackpoints": [
    {
      "clientTrackpointId": "uuid",
      "lat": 37.5665,
      "lng": 126.978,
      "recordedAt": "2026-09-01T10:01:00.000Z",
      "accuracy": 8.2
    }
  ]
}
```

## 응답 스키마

```json
{
  "success": true,
  "data": {
    "savedCount": 1
  }
}
```

## 인증/인가

- `authenticate`

## 검사하는 내용

- 세션 소유자 일치 여부
- 세션이 `IN_PROGRESS`인지 여부
- 좌표 값 범위
- 클라이언트 트랙포인트 ID 중복 여부

## 조회하는 상태

- 세션 idx `[running_sessions.idx]`
- 사용자 idx `[running_sessions.users_idx]`
- 세션 상태 `[running_sessions.status]`
- 클라이언트 트랙포인트 ID `[running_trackpoints.client_trackpoint_id]`

## 저장/변경하는 상태

- 클라이언트 트랙포인트 ID `[running_trackpoints.client_trackpoint_id]`
- 세션 idx `[running_trackpoints.running_sessions_idx]`
- 좌표 `[running_trackpoints.point]`
- 기록 시각 `[running_trackpoints.recorded_at]`
- 정확도 `[running_trackpoints.accuracy]`

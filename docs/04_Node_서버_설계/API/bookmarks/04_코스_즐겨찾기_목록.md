# 코스 즐겨찾기 목록

## 엔드포인트

- `GET /api/bookmarks/routes`

## 요청 스키마

```json
{
  "query": {
    "page": 1,
    "limit": 20
  }
}
```

## 응답 스키마

```json
{
  "success": true,
  "data": {
    "items": [
      {
        "bookmarkIdx": 1,
        "routeRecommendationIdx": 10,
        "name": "한강 5km 코스",
        "totalDistance": 5000,
        "totalAscent": 32.4,
        "slopeStd": 2.1
      }
    ],
    "page": 1,
    "limit": 20
  }
}
```

## 인증/인가

- `authenticate`

## 검사하는 내용

- 페이지네이션 값 범위
- 본인 즐겨찾기만 조회하는지 여부

## 조회하는 상태

- 즐겨찾기 idx `[route_bookmarks.idx]`
- 사용자 idx `[route_bookmarks.users_idx]`
- 추천 코스 idx `[route_bookmarks.route_recommendations_idx]`
- 추천 코스명 `[route_recommendations.name]`
- 총 거리 `[route_recommendations.total_distance]`
- 총 상승 고도 `[route_recommendations.total_ascent]`
- 경사 표준편차 `[route_recommendations.slope_std]`

## 저장/변경하는 상태

- 없음

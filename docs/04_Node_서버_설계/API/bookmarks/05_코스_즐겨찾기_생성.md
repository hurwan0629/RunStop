# 코스 즐겨찾기 생성

## 엔드포인트

- `POST /api/bookmarks/routes`

## 요청 스키마

```json
{
  "recommendationId": 10
}
```

## 응답 스키마

```json
{
  "success": true,
  "data": {
    "bookmarkIdx": 1,
    "routeRecommendationIdx": 10
  }
}
```

## 인증/인가

- `authenticate`

## 검사하는 내용

- 추천 코스 존재 여부
- 동일 코스 즐겨찾기 중복 여부
- 사용자에게 접근 가능한 코스인지 여부

## 조회하는 상태

- 추천 코스 idx `[route_recommendations.idx]`
- 사용자 idx `[route_bookmarks.users_idx]`
- 즐겨찾기 코스 idx `[route_bookmarks.route_recommendations_idx]`

## 저장/변경하는 상태

- 사용자 idx `[route_bookmarks.users_idx]`
- 추천 코스 idx `[route_bookmarks.route_recommendations_idx]`

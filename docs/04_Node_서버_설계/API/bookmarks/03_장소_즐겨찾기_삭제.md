# 장소 즐겨찾기 삭제

## 엔드포인트

- `DELETE /api/bookmarks/points/:bookmarkIdx`

## 요청 스키마

```json
{
  "params": {
    "bookmarkIdx": 1
  }
}
```

## 응답 스키마

```json
{
  "success": true,
  "data": {
    "deleted": true
  }
}
```

## 인증/인가

- `authenticate`

## 검사하는 내용

- 즐겨찾기 idx 형식
- 즐겨찾기 소유자 일치 여부

## 조회하는 상태

- 즐겨찾기 idx `[point_bookmarks.idx]`
- 사용자 idx `[point_bookmarks.users_idx]`

## 저장/변경하는 상태

- 장소 즐겨찾기 행 `[point_bookmarks.idx]`

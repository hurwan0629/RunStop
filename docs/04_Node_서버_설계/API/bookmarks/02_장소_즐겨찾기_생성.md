# 장소 즐겨찾기 생성

## 엔드포인트

- `POST /api/bookmarks/points`

## 요청 스키마

```json
{
  "name": "집 앞 공원",
  "lat": 37.5665,
  "lng": 126.978
}
```

## 응답 스키마

```json
{
  "success": true,
  "data": {
    "idx": 1,
    "name": "집 앞 공원",
    "lat": 37.5665,
    "lng": 126.978
  }
}
```

## 인증/인가

- `authenticate`

## 검사하는 내용

- 장소명 길이
- 좌표 값 범위
- 동일 이름 또는 동일 좌표 중복 처리 기준

## 조회하는 상태

- 사용자 idx `[point_bookmarks.users_idx]`
- 장소명 `[point_bookmarks.name]`
- 좌표 `[point_bookmarks.point]`

## 저장/변경하는 상태

- 사용자 idx `[point_bookmarks.users_idx]`
- 장소명 `[point_bookmarks.name]`
- 좌표 `[point_bookmarks.point]`

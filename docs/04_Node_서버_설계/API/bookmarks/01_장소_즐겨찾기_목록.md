# 장소 즐겨찾기 목록

## 엔드포인트

- `GET /api/bookmarks/points`

## 요청 스키마

```json
{
  "query": {
    "page": 1,
    "limit": 20
  }
}
```

## 응답 스키마

```json
{
  "success": true,
  "data": {
    "items": [
      {
        "idx": 1,
        "name": "집 앞 공원",
        "lat": 37.5665,
        "lng": 126.978
      }
    ],
    "page": 1,
    "limit": 20
  }
}
```

## 인증/인가

- `authenticate`

## 검사하는 내용

- 페이지네이션 값 범위
- 본인 즐겨찾기만 조회하는지 여부

## 조회하는 상태

- 즐겨찾기 idx `[point_bookmarks.idx]`
- 사용자 idx `[point_bookmarks.users_idx]`
- 장소명 `[point_bookmarks.name]`
- 좌표 `[point_bookmarks.point]`

## 저장/변경하는 상태

- 없음

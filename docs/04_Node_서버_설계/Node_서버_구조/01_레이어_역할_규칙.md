# 레이어 역할 규칙

## Controller

- 요청 DTO를 검증합니다.
- Service를 호출합니다.
- 정상 응답 래퍼를 만듭니다.

## Service

- 비즈니스 흐름을 조립합니다.
- 여러 Repository와 Adapter 호출을 묶습니다.
- 트랜잭션 시작 여부를 결정합니다.

## Repository

- DB 쿼리를 담당합니다.
- DB row와 애플리케이션 타입 사이의 매핑을 담당합니다.

## DTO

- 요청/응답 스키마를 정의합니다.
- Zod 기반 검증 기준을 제공합니다.

## Middleware

- 인증, 인가, 전역 에러, 비동기 에러 전달 같은 공통 HTTP 흐름을 처리합니다.

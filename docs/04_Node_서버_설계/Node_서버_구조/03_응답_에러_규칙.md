# 응답 및 에러 규칙

## 정상 응답

```json
{
  "success": true,
  "data": {}
}
```

## 에러 응답

```json
{
  "success": false,
  "error": {
    "code": "ERROR_CODE",
    "message": "사용자에게 전달할 메시지",
    "details": {}
  }
}
```

## 관리 기준

- 정상 응답은 Controller에서 생성합니다.
- 에러 응답은 `errorHandler`에서 생성합니다.
- `details`는 검증 실패나 추가 설명이 필요할 때만 사용합니다.

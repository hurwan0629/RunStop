# 인증인가 규칙

## authenticate

- `Authorization: Bearer <token>` 헤더를 확인합니다.
- JWT 서명과 기본 클레임을 검증합니다.
- DB에서 최신 사용자 상태와 권한을 조회합니다.
- 탈퇴, 정지 사용자는 요청을 막습니다.

## requireGuest

- 이미 로그인한 사용자가 접근하면 막습니다.
- 로그인, 회원가입, 계정 복구 API에 사용합니다.

## requireAdmin

- `authenticate` 이후 관리자 권한을 확인합니다.
- 관리자 전용 API에 사용합니다.

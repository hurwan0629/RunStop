# LLM 어댑터

## 역할

- LLM 기반 설명 생성, 추천 사유 생성, 사용자 안내 문구 생성을 담당합니다.
- Service가 특정 LLM SDK에 직접 의존하지 않도록 분리합니다.

## 설정 값

- LLM 사용 여부
- LLM API 키
- LLM 모델명

## 입력 기준

- 사용자 식별 정보는 필요한 최소 범위만 넘깁니다.
- 프롬프트 입력은 Adapter에서 외부 API 요청 형식으로 변환합니다.

## 출력 기준

- LLM 결과는 서버 내부 응답 타입으로 정리합니다.
- 외부 응답 원문은 필요한 경우 로그 또는 디버깅 정보로만 분리합니다.

## 주요 에러

- LLM 호출 실패
- 응답 파싱 실패
- 사용량 또는 제한 초과

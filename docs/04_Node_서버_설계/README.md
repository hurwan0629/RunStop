# Node 서버 설계 문서

이 폴더는 Node 서버의 전체 구조, API 흐름, 외부 어댑터 규칙을 나누어 관리합니다.

## 문서 구분

- [Node_서버_구조](./Node_서버_구조/README.md): 서버 전체 공통 규칙을 관리합니다.
- [API](./API/README.md): 도메인별 API 흐름과 검증 규칙, 저장 상태를 관리합니다.
- [어댑터](./어댑터/README.md): Worker, LLM, SMS, TMap 같은 외부 연동 모듈 규칙을 관리합니다.
- [계층별_함수](./계층별_함수/README.md): Controller, Service, Repository, Middleware, Adapter, Infra, DTO 함수 단위 책임을 관리합니다.

## 작성 기준

- 전체 구조를 보고 싶으면 `Node_서버_구조`를 봅니다.
- 특정 사용자 흐름을 보고 싶으면 `API`를 봅니다.
- 외부 시스템 연동 방식만 보고 싶으면 `어댑터`를 봅니다.
- 계층별 함수 시그니처와 작업 내용을 보고 싶으면 `계층별_함수`를 봅니다.
- API 문서는 API 1개를 파일 1개로 관리합니다.
- API 도메인 1개는 폴더 1개로 관리합니다.

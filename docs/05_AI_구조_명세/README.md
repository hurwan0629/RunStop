## 이 프로젝트를 한 줄로 설명하면

> 기존 `routing-worker`가 만든 여러 경로 후보를 대상으로, **사용자별 합성 Utility를 Ground Truth로 만들고 여러 Ranking 모델을 같은 조건에서 비교하는 독립 오프라인 실험 환경**이다.

현재 `ai/`는 운영 서비스 안에서 자동 학습하거나 자동 배포하는 코드가 아니다. 설정 UI와 CLI를 통해 실험을 만들고, 생성된 모델은 별도의 export 과정을 거쳐야 한다.

## 핵심 원칙

1. **운영 경로 생성 로직과 AI 실험을 분리한다.**
2. `condition_score`는 Baseline으로 남기고 합성 Utility 정답에 그대로 사용하지 않는다.
3. 모델 종류가 달라도 동일 Dataset / Split / Metric으로 비교한다.
4. Utility와 정답 순위는 모델 입력 Feature에서 제외한다.
5. 실제 사용자 선택 로그가 없으므로 현재 평가는 **합성 선호 가설에 대한 성능**이다.
6. 결과는 재현 가능하도록 설정, 데이터 해시, split, 환경, 예측, 지표, 자원 사용량을 Artifact에 남긴다.

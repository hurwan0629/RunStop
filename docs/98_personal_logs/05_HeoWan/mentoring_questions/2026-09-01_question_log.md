1. 알고리즘

경로 생성 알고리즘 관련해서 담당 팀원분이 기존의 다익스트라는 사용자의 의도와 다르게 점수가 높게 책정된 경로를 채택하는 방식에 문제가 있을 수 있다고 판단해서, 파이프라인 방식의 알고리즘을 짜는 게 좋지 않을까 하는 생각을 하셨다고 했습니다.

우선 제가 파이프라인 알고리즘 관련해서는 거의 모르기도 하고, 현재 서버 구조 및 DB를 다 완성해가고 있어서 한 번 알아보시고 알려주신다고 하셨는데 혹시 관련해서 다익스트라보다 더 좋은 방식이 있을까요?

(파이프라인 알고리즘은 찾아보아도 잘 나오지 않고, 현재 이야기해주신 분이 예비군 때문에 더 자세히 여쭤보지 못했습니다...)

2. 일정

현재 저희 팀은 9/8일까지 AI 및 추천 서비스를 제외하고 대부분 마무리한 뒤, 발표를 고려하여 약 10~12일 정도 AI를 공부하고 설계하여 만들려고 하는데 일정이 빠듯하다 보니 문제없이 좋은 결과를 낼 수 있을지 우려됩니다. 12일 정도면 AI를 만들어 문제없이 완성하기에 적합한 기간일까요?

(아무래도 학습 데이터가 관건이라고 생각하여 이 부분을 시간에 여유가 생긴 팀원 또는 제가 시간을 내서 학습 데이터를 만들어 놓으면 그래도 더 빨리 진행되지 않을까 싶지만, 역시 걱정이 됩니다.)

3. 현재 진행 방향

현재까지 서비스 정책을 거의 다 마치고, 설계하면서 조금씩 맞지 않는 부분을 맞춰가며 DB 및 API 설계를 진행하고 있습니다.

저번에 조언해주신 방식으로 작업하면서 1~2일 주기로 귀가 전까지 회의를 하고 진행도를 체크하고 있으며, 현재 진행 상황으로는 아래 파일처럼 금요일까지 서버 쪽이 알고리즘을 제외하고 완료될 것으로 보이고, 주말까지는 구현도 대부분 마무리되지 않을까 생각하고 있습니다.

서비스 구조 등과 같은 부분은 질문하기 애매하거나 직접 고민해서 해결할 수 있는 부분이 많다고 생각해서, 걱정되는 부분이 있더라도 우선 직접 부딪히면서 해결해나가려고 하고 있습니다.

현재 저희가 진행하고 있는 방향이나 작업 순서가 전체적으로 괜찮은지, 혹시 지금 시점에서 놓치고 있거나 수정하면 좋을 부분이 있는지도 한번 여쭤보고 싶습니다!

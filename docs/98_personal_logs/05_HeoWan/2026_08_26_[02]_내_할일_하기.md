# 1. 데이터베이스 먼저
- users: 사용자 기본 정보
  - idx: 식별자
  - nickname: 사용자에게 보여줄 이름
  - total_exp: 총 경험치 (레벨 + 다음 레벨까지 남은 경험치로 환산)
  - role: USER / ADMIN
  - created_at: 생성일자
  - updated_at: 수정일자
- user_profile: 사용자에 대한 데이터
  - user_idx: 식별자 및 FK -> users.id
  - fitness_score: 체력/러닝 수준
  - preferred_slope: 선호 경사
  - preferred_environment: 선호 환경 (JSON 또는 컬럼 나누기)
  - preferred_facilities: 선호 시설 (JSON 또는 컬럼 나누기)
  - updated_at: 수정 일자
- user_auths: 사용자가 등록한 OAuth 정보
  - idx: 식별자
  - user_idx: FK -> users.id
  - provider: GOOGLE / KAKAO
  - provider_user_id: OAuth 제공자의 사용자 ID
  - created_at: 생성일자

- running_goal: 사용자의 월간/주간 목표
  - idx: 식별자
  - user_idx: FK -> users.id
  - goal_type: enum[WEEKLY / MONTHLY]
  - target_distance: 목표 거리(m)
  - start_date: 시작일자
  - end_date: 종료일자 (예정)
  - created_at: 생성일자

- route_requests: 사용자가 입력한 경로 요청 정보
  - idx
  - prompt
  - ... (요소별 점수 컬럼, 원하는 높이 등) (경우에 따라 JSON)
  - created_at
- route_recommendation: 서비스에서 후보로 만든 경로들
  - idx: 식별자
  - route_requests_idx: 해당 후보가 만들어진 원본 사용자 요청
  - score: 알고리즘을 통해 만들어진 점수
  - created_at
- route_point: route에 대한 주요 지점들
  - idx: 식별자
  - route_recommendation_idx: 후보 경로 식별자
  - sequence: 경로 나열을 위한 순서 (route_choice, route_point.idx 복합 인덱스)
  - title: 지점 명칭
  - point_type: START, WAYPOINT, END 등
  - elevation: 경사도
  - latitude: 위도
  - longitude: 경도
- route_choice: 사용자가 선택한 경로
  - idx: 식별자
  - route_recommendation: 선택된 추천 경로
  - total_distance: 총 러닝 길이
  - total_ascent: 총 상승 고도
  - score: 다익스트라의 점수 책정
  - geometry: LineString(PostGIS)

- running_session: 한번의 러닝 전체 기록
  - idx: 식별자
  - route_recommendation_idx: 해당 러닝의 경로 식별자
  - started_at: 러닝 시작 시간
  - finished_at: 러닝 종료 시간
  - average_pase: running_trackpoint를 이용한 전체 평균
- running_trackpoint: 주기적으로 찍은 GPS 위치 기록
  - idx: 식별자
  - running_session_idx: 어떤 러닝에 대한 지점인지 설정
  - latitude: 위도
  - longitude: 경도
  - recorded_at: 기록 스냅샷 시각
  - accuracy: 정확도

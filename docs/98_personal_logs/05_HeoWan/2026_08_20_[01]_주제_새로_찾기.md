# 주제를 새로 찾아가고 있습니다.

`2026-08-20 14:52:02`

좋은 AI 서비스가 나온느 구조를 먼저 찾기

고려해야하는 시각은 다음과 같다고 생각합니다.
- 실제로 반복되는 문제
- 예측/판단할 대상이 명확함
- 학습 가능한 데이터
- 연구적 근거
- 결과를 사용자가 행동에 활용할 수 있음

> 사용자의 행동에 영향을 미칠 수 있어야함. (기획적인 요소)

> AI 프로젝트가 무너지는 흔한 이유로는 정답데이터와 특성 데이터가 존재하지 않는다는 점입니다. (프로젝트 진행 요소)

연구 논문의 경우에는 3가지 측면이 있습니다.
- 문제를 재기하기 위한 근거
- 변수 관계 근거 (모델링에 핵심)
- 모델 검증 (직접 증명을 위한 연구)

## 중요 요소들 정리
- 사용자는 누구인지
- 사용자가 실제로 사용할지
- 사용자를 실제로 행동으로 이끌 수 있는지
- 데이터는 존재하는지
- 예측하려는 정답은 무엇인지
- AI를 굳이 쓸 필요가 있는지
- 관계 (모델링)의 근거가 있는지

  4. 예측

## 문제 찾기

주로 내(허완)가 하는일: `서점, 카페, 운동, 공부(it 및 컴퓨터 이용), 교통, 생각정리, 책은 보고싶은데 많이 못보고, 문서정리`

이런 측면에서 문제를 찾아보면
1. `서점`: 좋은 책을 찾는것이 어렵다. 책은 정보 뿐만 아니라 세계관을 자신의 세계에 넣는 행위인데 (정보는 이제 찾을려면 찾는게 어렵지 않으니까) 그러기 위해 시간을 투자할만한, 나에게 좋은 **영향을 줄만한 책을 읽을 동기를 줄 요소도 없고 구매해도 허탕치는 경우가 많다**

2. `카페`: 카페에서 커피를 살 때 매일 사야하는데 매일 어플로도 주문하는 것이 귀찮습니다. 하지만 자동화를 하기에는 주문하지 않는 경우도 있습니다.

3. `카페`: 카페에 앉아서 공부를 하려는데 자리가 없거나 와이파이가 부득이하게 되지 않는 경우도 있습니다.

4. `공부`: 공부 해야할 주제들도 많고 업무(작업)과 공부의 비율을 맞추지 못하는 경우가 생깁니다. 공부를 제대로 안하면 작업중에 막히는데 주먹구구식으로 작업되는 경우도 있고 작업을 하지 않으면 공부한 내용을 실제로 쓰지 않아서 무용지물이 되는 경우가 많습니다.

5. `생각정리`: 생각을 구조화하는 기법이 있는걸로 알기도 하고 요즘 llm을 이용하여 생각을 정리하기도 하는데 중요한건 나의 세계관을 만드는 것인거같습니다. 그 중에서는 각오를 다지지 못하는 경우도 있고, 실제로 마음은 A쪽인데 생각은 B 쪽인 경우도 있습니다.

6. `교통`: 혼잡도 관련해서는 애초에 서비스가 많지 않나라고 생각하고 특별히 매일되는 루틴이라 오히려 별 생각이 없습니다. 하지만 앉아서 가는게 편하지만 보통 버스를 타서 불편함을 느낀적도 없고 혼잡도를 알아도 통학 시간은 변경하지 못하여 큰 의미가 없는 것 같습니다. 요즘에는 지도에도 많은 기능이 잇습니다.

7. `문서정리`: 요즘에 공부하는 폴더에서 점점 공부 기록, 개념정리, 코드연습, 데이터셋 등등을 한쪽으로 몰아서 작업을 하다보니 정리를 해야하기도 합니다. 하지만 이건 cli llm을 활용하면 지금도 불편함이 거의 느껴지지 않습니다. 오히려 개인이 만든것으로 괜히 이상한 민감한 파일을 건드리지 않을까 걱정이 되어 그런쪽으로 만들진 못할 것 같습니다. 

8. `협업 관리`: 차라리 방향을 협업 관리로 가서 로컬 AI를 이용해서 민감한 보안 문제를 해결해줄만한, 여러 사용자가 사용하는? 예를 들어 워크플로우를 자동으로 관리 및 모니터링, 그리고 작업을 해주는 툴을 만드는 것은 어떨까? 라는 생각이 듭니다. 지금 하고있는데로 기획시에도 특정 요소들이 문제 없이 잘 되어가는지 확인을 하는 `zira`의 AI 서비스 또는 그의 변형이면 괜찮지 않을까 싶습니다.

9. `책`: 책을 많이 못보는 경우에도 말한대로 요약도 중요하지만 그 가치관을 사용자의 내면에 주입하는 거을 도와야합니다. 정보 자체는 이제 흔해서 정보를 제공하는 것 만으로는 충분하지 않고 사용자의 행동에 영향을 미칠 수 있어야합니다.

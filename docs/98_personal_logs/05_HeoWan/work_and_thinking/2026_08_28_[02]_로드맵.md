# 집중하기
현재 집중이 잘 되지 않는 것 같아 한번 해야하는 일들을 정리해서 가보려고 합니다.

## 1. 전체 진행방향 정리하기
일단 최우선 목표는 프로젝트 완성입니다.

프로젝트 완성은 `런스톱 서비스를 명확하게 나타내기`이고

런스톱 서비스는 `사용자가 선호하는 요소를 추출하여 사용자 만족도에 맞게 추천해주는 서비스입니다.`

사용 기술은

1. React Native
2. NodeJS
3. Python Worker
4. Postgres + GIS

로 고정되었으며 필요에 따라 데이터 서버를 분리할 수 있습니다.

> 최소 9월 7일까지 마무리를 해야 안정적으로 프로젝트를 완수할 수 있겠다고 판단하였습니다.

## 2. 현재 진행중인 사항 (8/31 까지)
### 1. 서비스 아키텍처
- `데이터베이스`: 현재 작업을 대강 끝냈으나 프론트와 알고리즘/데이터의 작업이 완료되어야 이어질 수 있기 때문에 일단 최소 작업만 해놓았습니다.
- `서버 구조 생성`: 
  - 인터페이스 생성
  - 파이썬 워커 생성 모듈화
  - API 호출 모듈화
- 클라우드 및 도커 환경 준비
- TMAP API, 서비스 자체 로그인, PostGIS 기술 공부
> 여유가 되면 알고리즘 쪽으로 붙을 생각입니다.

### 2. 프론트
- 현재 작업중이며 오늘 작업 진행 상황을 받을 예정이며 일단 월요일(8/31)까지 프론트에서 요구하는 API, 정책 들을 받아서 정리를 할 예정입니다.
- 프론트의 전체적인 디자인 수정 요청이 있었으며 현재 반영을 위한 작업중입니다.

### 3. 데이터 및 알고리즘
- 데이터는 모두 `EPSG:4326`형식으로 통일해주었으며 경사도의 경우만 `EPSG:5179`으로 저장 후 `.py` 모듈을 이용하여 경사도를 뽑는 형태로 진행 예정 되었습니다.
- 피처를 이용한 경로 점수화를 테스트해야합니다.

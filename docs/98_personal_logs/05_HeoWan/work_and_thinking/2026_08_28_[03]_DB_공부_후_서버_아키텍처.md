데이터베이스는 스키마를 나누어 테이블 관리가 용이하게 설정하엿습니다.

마이그레이션을 db 스키마 및 테이블, index 등을 생성해야 볼륨이 이미 있을 때에도 직접 사용하기 편하다 생각하여 node의 prisma migration또는 sqlalembic를 사용하는 것이 좋겠다고 판단하였습니다.

`.csv`를 데이터베이스에 넣는 것도 
```SQL
COPY dataset.cctv(...)
FROM '/data/cctv.csv'
WITH (
  FORMAT csv
  HEADER true
);
```
와 같이 작성이 가능하여 db를 migration으로 만든 후 데이터셋을 `import` 하면 좋겠다 판단하였습니다. 것으로 넣으면 좋겠다 생각하였습ㄴ디ㅏ.

또한 스키마에서 `datasets`과 `service` 스키마의 권한을 각각

| 스키마 | Node | Python Worker |
|---|---|---|
| `service` | `READ`/`WRITE` | `READ` |
| `datasets` | `READ` | `READ`/`WRITE` |

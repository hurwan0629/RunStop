# RunStop 서비스 설계

일단 해당 서비스는 다음과 같은 위경도가 있는 지리 요소+ 를 이용하여 맞춤 러닝 경로를 제공해주는 서비스이다.

- 공중 화장실
- 스마트 거리등
- safemap_편의점
- 와이파이
- 자전거 보관소
- 등고선 (경사도)
- 서울 CCTV 
- 공원 지역

기본적인 사용자의 플로우는 다음과 같다.
1. 로그인
2. 사용자 정보 / 선호 설정
3. 러닝 조건 입력
4. 경로 추천 알고리즘 실행
5. 경로 후보 제공
6. 사용자가 경로 선택
7. 러닝 시작
8. GPS 기반 실제 이동 경로 기록
9. 러닝 종료
10. 러닝 기록 저장

# 서비스에 존재해야하는 데이터
> 서비스에 존재해야하는 데이터는 다음과 같다.
- users: 사용자 기본 정보
  - idx: 식별자
  - nickname: 사용자에게 보여줄 이름
  - total_exp: 총 경험치 (레벨 + 다음 레벨까지 남은 경험치로 환산)
  - role: USER / ADMIN
  - created_at: 생성일자
  - updated_at: 수정일자
- user_profile: 사용자에 대한 데이터
  - user_idx: 식별자 및 FK -> users.id
  - fitness_score: 체력/러닝 수준
  - preferred_slope: 선호 경사
  - preferred_environment: 선호 환경 (JSON 또는 컬럼 나누기)
  - preferred_facilities: 선호 시설 (JSON 또는 컬럼 나누기)
  - updated_at: 수정 일자
- user_auths: 사용자가 등록한 OAuth 정보
  - idx: 식별자
  - user_idx: FK -> users.id
  - provider: GOOGLE / KAKAO
  - provider_user_id: OAuth 제공자의 사용자 ID
  - created_at: 생성일자

- running_goal: 사용자의 월간/주간 목표
  - idx: 식별자
  - user_idx: FK -> users.id
  - goal_type: enum[WEEKLY / MONTHLY]
  - target_distance: 목표 거리(m)
  - start_date: 시작일자
  - end_date: 종료일자 (예정)
  - created_at: 생성일자

- route_requests: 사용자가 입력한 경로 요청 정보
  - idx
  - prompt
  - ... (요소별 점수 컬럼, 원하는 높이 등) (경우에 따라 JSON)
  - created_at
- route_recommendation: 서비스에서 후보로 만든 경로들
  - idx: 식별자
  - route_requests_idx: 해당 후보가 만들어진 원본 사용자 요청
  - score: 알고리즘을 통해 만들어진 점수
  - created_at
- route_choice: 사용자가 선택한 경로
  - idx: 식별자
  - route_recommendation: 선택된 추천 경로
  - total_distance: 총 러닝 길이
  - total_ascent: 총 상승 고도
  - score: 다익스트라의 점수 책정
  - geometry: LineString(PostGIS)
- route_point: route에 대한 주요 지점들
  - idx: 식별자
  - route_idx: 본 경로 식별자
  - sequence: 경로 나열을 위한 순서 (route_choice, route_point.idx 복합 인덱스)
  - title
  - point_type: START, WAYPOINT, END 등
  - elevation: 경사도
  - latitude: 위도
  - longitude: 경도

- running_session: 한번의 러닝 전체 기록
  - idx: 식별자
  - started_at: 러닝 시작 시간
  - finished_at: 러닝 종료 시간
  - average_pase: running_trackpoint를 이용한 전체 평균
- running_trackpoint: 주기적으로 찍은 GPS 위치 기록
  - idx: 식별자
  - running_session_idx: 어떤 러닝에 대한 지점인지 설정
  - latitude: 위도
  - longitude: 경도
  - recorded_at: 기록 스냅샷 시각
  - accuracy: 정확도

- 코스 추천에서 추천받기 버튼 누르고 이동하는 추천 코스에서 사용자에게 코스를 보여주는게 좋을 듯 함. 또한 지도에 사용자가 요청한 요소가 점 또는 포인트로 찍히거나 토글로 껐다 킬 수 있게 하면 좋을 듯 함.
- 코스 선택 이후 자동 시작한다 치면 타이머나 진행중인 러닝이 홈 화면 또는 어딘가에 나와야함.

# 서비스에 존재해야하는 데이터
> 서비스에 존재해야하는 데이터는 다음과 같다.
- users: 사용자 기본 정보
  - idx: 식별자
  - nickname: 사용자에게 보여줄 이름
  - total_exp: 총 경험치 (레벨 + 다음 레벨까지 남은 경험치로 환산)
  - role: USER / ADMIN
  - created_at: 생성일자
  - updated_at: 수정일자
- user_profile: 사용자에 대한 데이터
  - user_idx: 식별자 및 FK -> users.id
  - fitness_score: 체력/러닝 수준
  - preferred_slope: 선호 경사
  - preferred_environment: 선호 환경 (JSON 또는 컬럼 나누기)
  - preferred_facilities: 선호 시설 (JSON 또는 컬럼 나누기)
  - updated_at: 수정 일자
- user_auths: 사용자가 등록한 OAuth 정보
  - idx: 식별자
  - user_idx: FK -> users.id
  - provider: GOOGLE / KAKAO
  - provider_user_id: OAuth 제공자의 사용자 ID
  - created_at: 생성일자

- running_goal: 사용자의 월간/주간 목표
  - idx: 식별자
  - user_idx: FK -> users.id
  - goal_type: enum[WEEKLY / MONTHLY]
  - target_distance: 목표 거리(m)
  - start_date: 시작일자
  - end_date: 종료일자 (예정)
  - created_at: 생성일자

- route_requests: 사용자가 입력한 경로 요청 정보
  - idx
  - prompt
  - ... (요소별 점수 컬럼, 원하는 높이 등) (경우에 따라 JSON)
  - created_at
- route_recommendation: 서비스에서 후보로 만든 경로들
  - idx: 식별자
  - route_requests_idx: 해당 후보가 만들어진 원본 사용자 요청
  - score: 알고리즘을 통해 만들어진 점수
  - created_at
- route_choice: 사용자가 선택한 경로
  - idx: 식별자
  - route_recommendation: 선택된 추천 경로
  - total_distance: 총 러닝 길이
  - total_ascent: 총 상승 고도
  - score: 다익스트라의 점수 책정
  - geometry: LineString(PostGIS)
- route_point: route에 대한 주요 지점들
  - idx: 식별자
  - route_idx: 본 경로 식별자
  - sequence: 경로 나열을 위한 순서 (route_choice, route_point.idx 복합 인덱스)
  - title
  - point_type: START, WAYPOINT, END 등
  - elevation: 경사도
  - latitude: 위도
  - longitude: 경도

- running_session: 한번의 러닝 전체 기록
  - idx: 식별자
  - started_at: 러닝 시작 시간
  - finished_at: 러닝 종료 시간
  - average_pase: running_trackpoint를 이용한 전체 평균
- running_trackpoint: 주기적으로 찍은 GPS 위치 기록
  - idx: 식별자
  - running_session_idx: 어떤 러닝에 대한 지점인지 설정
  - latitude: 위도
  - longitude: 경도
  - recorded_at: 기록 스냅샷 시각
  - accuracy: 정확도

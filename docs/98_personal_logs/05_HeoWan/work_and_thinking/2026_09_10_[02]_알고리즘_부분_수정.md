## `ROUND_TRIP + via` 경로 생성 방식 수정 
`2026-09-10 22:04:55`

경유지가 있는 `ROUND_TRIP` 요청에서 `LOOP`와 같은 방식으로 순환 경로가 만들어지던 부분을 분리했습니다.

수정 파일은 다음과 같습니다.
- `routing/candidates.py`
  - `generate_candidates_via()`
- `routing/course.py`
  - `_generate_out_and_back_via()`
  - `generate_course_via()`

기존 로직은 다음과 같습니다.
```text
LOOP + via
ROUND_TRIP + via
→ 둘 다 start → vias → start 형태로 _route_chain() 처리
→ 구간별 used_edges penalty가 적용되어 돌아오는 길이 달라질 수 있음
```

새로운 로직은 다음과 같습니다.
```text
LOOP + via
→ 기존처럼 start → vias → start 를 _route_chain()으로 연결
→ used_edges penalty로 다른 길 복귀 유도

ROUND_TRIP + via
→ start → vias → optional turnaround 까지 편도 경로 생성
→ outbound_nodes를 역순으로 붙여 동일 경로 복귀 보장
```

핵심 변경은 `generate_course_via()`가 `mode`를 받아 `out_and_back`일 때만 `_generate_out_and_back_via()`로 분기하도록 만든 것입니다.

## `ONE_WAY` 타원 waypoint 선택 방식 수정 
`2026-09-10 22:21:31`

`ONE_WAY` 경로에서 start/end를 초점으로 하는 타원 waypoint를 고를 때, start-end 축 위 또는 대각선 방향의 점이 선택될 수 있던 부분을 제한했습니다.

수정 파일은 다음과 같습니다.
- `routing/course.py`
  - `_build()`

기존 로직은 다음과 같습니다.
```text
ellipse_waypoints(start, end, n=8)
→ bearing 값을 45도 단위 인덱스로 변환
→ 0~7번 타원점 중 하나를 선택
→ start-end 축 위의 점이나 대각선 점이 선택될 수 있음
```

새로운 로직은 다음과 같습니다.
```text
ellipse_waypoints(start, end, n=8)
→ start-end 선분에 수직인 2번/6번 타원점만 사용
→ bearing 반복값은 좌/우 방향을 번갈아 선택하는 용도로만 사용
```

핵심 변경은 `point_to_point` 분기에서 waypoint 인덱스를 `2` 또는 `6`으로 제한한 것입니다.

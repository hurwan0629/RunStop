## DTO 흐름대로 보기
### 1. 프론트 요청 
> `POST /api/routes/recommend` 요청을 하게됩니다.
```json
{
  "start": {
    "latitude": 37.543,
    "longitude": 127.044
  },
  "end": {
    "latitude": 37.543,
    "longitude": 127.044
  },

  "wayPoints": [
    {
      "name": "편의점",
      "coordinate": {
        "latitude": "float",
        "longitude": "float"
      }
    }
  ],

  // LOOP / ONE_WAY / ROUND_TRIP 중 하나
  "routeType": "LOOP",
  // 사용자가 원하는 거리
  "targetDistanceKm": 7.0,
  // 허용 거리 오차 % (아직 후보)
  "distanceTolerance": 10,

  // 필수 조건
  "requirements": {
    "toilet": true
  },

  // 가중치는 데이터 수집 후 28~31일에 명확히 설정
  "weights": {
    "distance": 5,
    "elevation": 4,
    "toilet": 5,
    "store": 2,
    "park": 3,
    "night": 5
  }
}
```

### 3. TMAP 응답에서 Backend 형식으로 변환

### 4. GIS의 LineString로 변환
> PostGIS를 이용하여 LineString로 변환하여 buffer 및 점수화를 진행합니다.
- PostGIS를 공부한 뒤 해결할 영역입니다. 
- PostGIS에서 Point와 LineString의 거리를 계산할 수 있는 기능을 제공한다고 확인하였습니다.
- 기본 좌표계는 `EPSG:4326`(위경도)이며 거리 계산시에 `EPSG:5179`(평면 좌표)입니다.
- 이 부분에서 **알고리즘**과 함께 경로를 계산하여 DB에 저장하게 됩니다.
- 유사 경로는 제거하며 점수화를 통해 후보 3군 생성 또는 완벽한 결과가 없음을 나타내게 됩니다.

course.py
이게 파일에 심장이라고 나와있기는 한데 그냥 중심에서 이런저런 모듈들을 잡아주는 역할이라고 생각하고있어.

course에서 실제 shortest_path를 이용해서 잡아주는거고

shortest_path는 사용자 지정 또는 waypoint로 만들어진 경유지를 지나는 경로를 잡아준다고 생각하면 course는 via를 반드시 지나는 경로를 만들어주고 mode 또한 via로 만들어준다고 하면 generate_course()의 경우에는 vias가 없을 경우, 일단 만든다음에 부족한 거리를 waypoint로 매꾸는 방식을 이용하고 있어.

여기에서 볼 포인트가 점수화하고 분기라고 생각하는데

분기를 먼저 보면 일단 vias가 존재하는 경우에는 무조건 generate_course_via()를 사용하는 방식이고, 거기에서 point_to_point ONE_WAY인 경우에는 반드시 end를 요구하게 되고, loop: LOOP, out_and_back: ROUND_TRIP 방식의 경우에는 end가 있어도 무시하는 방식으로 진행이 되는거같아. 전부 다 circle_waypoints를 이용해서 구하는 형태여서 wn-s 를 갔다오는 방식으로 구현이 되는거같아.

# recommend 입출력 스키마

> [!info] 빠른 위치 파악
> - **상태:** 현재 구현
> - **소스 위치:** `routing-worker/src/algo/pipeline.py::recommend`
> - **역할:** Node/FastAPI parser에서 참고할 `recommend()` 요청/응답 형태를 정리한다.

## 요청 스키마

```python
recommend(
    G: nx.Graph,
    idx: Any,
    route_type: "LOOP" | "ONE_WAY" | "ROUND_TRIP",
    start: tuple[float, float],
    target_km: float,
    end: tuple[float, float] | None = None,
    vias: list[tuple[float, float]] | None = None,
    weights: dict[str, int | float] | None = None,
    requirements: dict[str, object] | None = None,
    n_directions: int = 12,
    top_k: int = 3,
) -> list[CandidateRoute]
```

## 응답 스키마

```python
CandidateRoute = {
    "mode": str,
    "target_distance_m": float,
    "actual_distance_m": int,
    "distance_error_pct": float,
    "overlap_ratio": float,
    "scale_m": int,
    "coords": list[tuple[float, float]],

    "slope": {
        "avg_slope_pct": float | None,
        "max_slope_pct": float | None,
        "slope_std_pct": float | None,
        "elevation_gain_m": float | None,
        "elevation_loss_m": float | None,
        "sample_count": int,
    },

    "facilities": dict[str, int | float | None],

    "nature": {
        "park_ratio": float | None,
        "water_ratio": float | None,
    },

    "surface": {
        "length_m": float,
        "walkable_ratio": float | None,
        "bigroad_ratio": float | None,
        "stairs_count": int,
        "signal_per_km": float | None,
        "crossing_per_km": float | None,
    },

    "sub_scores": dict[str, float | None],
    "condition_score": float,
    "failed_conditions": list[str],
    "exact_match": bool,
    "estimated_minutes": int,
}
```

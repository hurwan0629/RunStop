# recommend 입출력 스키마

> 소스 위치: `routing-worker/src/algo/pipeline.py::recommend`

## 함수 시그니처

```python
recommend(
    G: nx.Graph,
    idx: Any,
    route_type: "LOOP" | "ONE_WAY" | "ROUND_TRIP",
    start: tuple[float, float],
    target_km: float,
    end: tuple[float, float] | None = None,
    vias: list[tuple[float, float]] | None = None,
    weights: dict[str, int] | None = None,
    requirements: dict[str, bool | int | float] | None = None,
    n_directions: int = 12,
    top_k: int = 3,
) -> list[CandidateRoute]
```

## 요청 필드

- `G`: NetworkX 도로 그래프입니다.
- `idx`: 좌표를 그래프 node로 변환하는 `NodeIndex`입니다.
- `route_type`: `LOOP`, `ROUND_TRIP`, `ONE_WAY` 중 하나입니다.
- `start`: 시작 좌표이며 `(lat, lon)` 순서입니다.
- `target_km`: 목표 거리이며 km 단위입니다.
- `end`: 도착 좌표입니다. `ONE_WAY`에서는 필수입니다.
- `vias`: 경유 좌표 목록입니다. 값이 있으면 via 후보 생성기를 사용합니다.
- `weights`: 사용자 선호 가중치입니다.
- `requirements`: 필수 조건입니다.
- `n_directions`: 후보 생성 방향 수입니다.
- `top_k`: 최종 반환 후보 수입니다.

## weights 허용 키

```python
{
    "distance": 1..5,
    "elevation": 1..5,
    "safety": 1..5,
    "night": 1..5,
    "nature": 1..5,
    "park": 1..5,
    "surface": 1..5,
    "flow": 1..5,
    "overlap": 1..5,
    "toilet": 1..5,
    "store": 1..5,
}
```

- `safety`와 `night`는 조명/야간 안전 계열 선호로 사용됩니다.
- `nature`와 `park`는 자연/공원 계열 선호로 사용됩니다.
- `toilet`, `store`, `park`, `night`, `surface`, `flow`, `overlap`은 scoring 단계의 sub-score 가중평균에도 사용됩니다.

## requirements 허용 키

```python
{
    "toilet": bool,
    "store": bool,
    "park": bool,
    "no_stairs": bool,
    "max_slope_pct": int | float,
    "max_slope": int | float,
    "maxSlope": int | float,
}
```

- `no_stairs`와 최대 경사 조건은 edge 탐색 중 hard constraint로 쓰입니다.
- `toilet`, `store`, `park`, `no_stairs`는 scoring 이후 `failed_conditions`, `exact_match` 계산에도 쓰입니다.
- 최대 경사 키의 우선순위는 `max_slope_pct` → `max_slope` → `maxSlope`입니다.

## 반환 스키마

```python
CandidateRoute = {
    "mode": str,
    "target_distance_m": float,
    "actual_distance_m": int,
    "distance_error_pct": float,
    "overlap_ratio": float,
    "scale_m": int,
    "coords": list[tuple[float, float]],

    "slope": {
        "avg_slope_pct": float | None,
        "max_slope_pct": float | None,
        "slope_std_pct": float | None,
        "elevation_gain_m": float | None,
        "elevation_loss_m": float | None,
        "sample_count": int,
    },

    "facilities": {
        "<facility>_count": int,
        "<facility>_per_km": float,
        "<facility>_nearest_m": float | None,
    },

    "nature": {
        "park_ratio": float | None,
        "water_ratio": float | None,
    },

    "surface": {
        "length_m": float,
        "walkable_ratio": float | None,
        "bigroad_ratio": float | None,
        "stairs_count": int,
        "signal_per_km": float | None,
        "crossing_per_km": float | None,
    },

    "sub_scores": dict[str, float | None],
    "condition_score": float,
    "failed_conditions": list[str],
    "exact_match": bool,
    "estimated_minutes": int,
}
```

## 반환 전 처리

- 후보 생성 직후에는 내부 계산용 `nodes`가 존재합니다.
- feature 추출과 scoring이 끝난 뒤 `nodes`는 `pipeline.py`에서 제거됩니다.
- 최종 후보 선택은 `select_candidates_with_ai(cands, weights, requirements, top_k)`를 통해 수행됩니다.

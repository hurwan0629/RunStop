# Feature 계층 전체 흐름

> [!info] 빠른 위치 파악
> - **상태:** 현재 구현
> - **소스 위치:** `routing-worker/src/algo/pipeline.py`
> - **역할:** 후보 pool 각각에 네 종류의 feature profile을 순서대로 부착한다.
> - **이전 단계:** [[INDEX]]
> - **다음 단계:** [[02. Elevation - DEM과 경사]]
> - **주요 입력:** cands
> - **주요 출력:** feature-enriched cands

## 입력 시점의 cand

대략:

```python
{
    "mode": ...,
    "target_distance_m": ...,
    "actual_distance_m": ...,
    "distance_error_pct": ...,
    "overlap_ratio": ...,
    "scale_m": ...,
    "coords": [...],
    "nodes": [...]
}
```

## Feature의 데이터 의존성

| Feature | 경로에서 쓰는 값 | 추가 데이터 |
|---|---|---|
| slope | `coords` | DEM |
| facilities | `coords` | 통합 시설 CSV |
| nature | `coords` | 공원/하천 GeoJSON |
| surface | `nodes` | G 자체의 OSM edge/node 속성 |

즉 공간 주변을 보는 세 모듈은 주로 `coords`를 사용하고, 실제 도로 속성을 보는 surface는 `nodes + G`를 사용한다.

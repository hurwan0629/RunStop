# Facilities - 주변 시설

> [!info] 빠른 위치 파악
> - **상태:** 현재 구현
> - **소스 위치:** `routing-worker/src/algo/features/facilities.py`
> - **역할:** 통합 시설 CSV의 각 시설 유형을 경로 주변 buffer에서 검색해 개수/밀도/최근접 거리를 만든다.
> - **이전 단계:** [[02. Elevation - DEM과 경사]]
> - **다음 단계:** [[04. Nature - 공원과 하천]]
> - **주요 입력:** cand.coords, 서울_시설데이터_통합.csv
> - **주요 출력:** FacilityProfile

## 데이터 로딩

CSV는 한 번만 읽고 `유형`별 EPSG:5179 좌표 배열로 캐시한다.

현재 코드가 기대하는 유형:

```text
화장실 → toilet
편의점 → store
도시공원 → park
가로등 → light
보안등 → security
보행등 → walklight
CCTV → cctv
```

## 공간 계산

```text
coords
→ EPSG:5179 LineString
→ FACILITY_BUFFER_M(현재 50m) buffer polygon
```

시설 검색은 두 단계다.

```text
1) buffer bounding box로 후보 점 축소
2) 실제 buffer polygon contains 계산
```

그리고 경로 line까지의 nearest distance도 계산한다.

## 시설별 현재 출력

각 유형마다:

```text
{key}_count
{key}_per_km
{key}_nearest_m
```

예:

```python
{
    "toilet_count": 2,
    "toilet_per_km": 0.64,
    "toilet_nearest_m": 38.5,
}
```

추가로 현재 profile 자체에:

```text
route_length_km
buffer_m
```

도 들어간다.

## 의미

- `count`: 요구조건/UI에 직관적
- `per_km`: 코스 길이가 다른 후보 비교에 유리
- `nearest_m`: 시설이 “있기만 한가”가 아니라 얼마나 가까운지 표현

> [!note]
> 시설 buffer는 `FACILITY_BUFFER_M`으로 관리한다. Nature와 같은 값을 공유하지 않는다.

# Feature Profile 데이터 형태

> [!info] 빠른 위치 파악
> - **상태:** 현재 구현
> - **소스 위치:** `routing-worker/src/algo/types.py`
> - **역할:** 네 Feature 모듈의 현재 출력 형태와 CandidateRoute 결합 모습을 한곳에서 본다.
> - **이전 단계:** [[05. Surface - OSM 도로 환경]]
> - **다음 단계:** [[07. 현재 한계점]]
> - **주요 입력:** 각 analyze_* 함수 결과
> - **주요 출력:** feature-enriched CandidateRoute

## ElevationProfile

```python
{
    "avg_slope_pct": float | None,
    "max_slope_pct": float | None,
    "elevation_gain_m": float | None,
    "sample_count": int,
}
```

## FacilityProfile

동적 key 구조:

```python
{
    "route_length_km": float,
    "buffer_m": float,

    "{facility}_count": int,
    "{facility}_per_km": float,
    "{facility}_nearest_m": float | None,
    ...
}
```

## NatureProfile

```python
{
    "park_ratio": float | None,
    "water_ratio": float | None,
}
```

## SurfaceProfile

```python
{
    "length_m": float,
    "walkable_ratio": float | None,
    "bigroad_ratio": float | None,
    "stairs_count": int,
    "signal_per_km": float | None,
    "crossing_per_km": float | None,
}
```

## 결합

```python
cand["slope"] = ...
cand["facilities"] = ...
cand["nature"] = ...
cand["surface"] = ...
```

이 상태가 현재 `weighting.py`가 기대하는 입력이다.

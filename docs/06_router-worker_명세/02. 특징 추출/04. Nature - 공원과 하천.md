# Nature - 공원과 하천

> [!info] 빠른 위치 파악
> - **상태:** 현재 구현
> - **소스 위치:** `routing-worker/src/algo/features/nature.py`
> - **역할:** 경로 주변 buffer 면적 중 공원/하천 polygon과 겹치는 비율을 계산한다.
> - **이전 단계:** [[03. Facilities - 주변 시설]]
> - **다음 단계:** [[05. Surface - OSM 도로 환경]]
> - **주요 입력:** cand.coords, 서울_공원.geojson, 서울_하천_polygon.geojson
> - **주요 출력:** NatureProfile

## 현재 데이터

```python
NATURE_LAYER_PATHS = {
    "park":  ".../서울_공원.geojson",
    "water": ".../서울_하천_polygon.geojson",
}
```

GeoJSON은 읽은 뒤 EPSG:5179로 투영하고 공간 인덱스를 미리 구축해 캐시한다.

## 계산

```text
route coords
→ EPSG:5179 LineString
→ NATURE_BUFFER_M(현재 50m) buffer
→ spatial index로 intersect 후보 polygon 조회
→ 후보 polygon union
→ 실제 교집합 면적 계산
```

비율:

\[
nature\_ratio =
\frac
{Area(RouteBuffer \cap NaturePolygon)}
{Area(RouteBuffer)}
\]

현재 출력:

```python
{
    "park_ratio": float | None,
    "water_ratio": float | None,
}
```

## 0과 None

```text
0.0
→ 데이터는 존재하지만 buffer와 자연 polygon이 겹치지 않음

None
→ 해당 GeoJSON 파일 자체가 없어 측정 불가
```

> [!note]
> Nature buffer는 `NATURE_BUFFER_M`으로 관리한다. 시설은 Point의 주변성, Nature는 Polygon의 환경 노출 비율을 보기 때문에 별도 상수로 둔다.

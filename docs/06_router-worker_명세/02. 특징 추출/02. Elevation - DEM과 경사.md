# Elevation - DEM과 경사

> [!info] 빠른 위치 파악
> - **상태:** 현재 구현
> - **소스 위치:** `routing-worker/src/algo/features/elevation.py`
> - **역할:** 경로 좌표를 일정 간격으로 샘플링하고 DEM 고도로 구간 경사와 누적 상승고도를 만든다.
> - **이전 단계:** [[01. Feature 계층 전체 흐름]]
> - **다음 단계:** [[03. Facilities - 주변 시설]]
> - **주요 입력:** cand.coords, DEM get_elevation()
> - **주요 출력:** ElevationProfile

## 1. 경로 샘플링

기본:

```text
SLOPE_SAMPLE_M = 30m
```

경로 segment 길이를 누적하다가 30m 이상이 되면 해당 end coordinate를 샘플로 추가한다.

> [!note]
> 정확히 매 30.000m 위치를 보간하는 방식이 아니라, 원래 polyline node들을 따라 누적하다 임계치를 넘는 end 좌표를 채택하는 방식이다.

## 2. DEM 고도 조회

```python
elevations_m = [
    get_elevation(lat, lon)
    for lat, lon in sampled_coordinates
]
```

DEM 범위 밖이면 `None`일 수 있고 해당 구간은 건너뛴다.

## 3. 구간 경사

\[
slope\_pct =
\frac{|elevation_2-elevation_1|}
{segment\_distance}
\times 100
\]

`MIN_SEGMENT_M=1m`보다 짧은 segment는 제외한다.

## 4. 현재 생성 값

```python
ElevationProfile = {
    "avg_slope_pct": float | None,
    "max_slope_pct": float | None,
    "elevation_gain_m": float | None,
    "sample_count": int,
}
```

`elevation_gain_m`은:

```python
if end_elevation > start_elevation:
    gain += end_elevation - start_elevation
```

처럼 **오르막만 누적**한다.

## 결측

유효한 slope segment가 하나도 없으면:

```python
{
    "avg_slope_pct": None,
    "max_slope_pct": None,
    "elevation_gain_m": None,
    "sample_count": ...
}
```

을 반환한다.

> [!warning] 인지된 확장 예정
> `slope_std_pct`, `elevation_loss_m`, `elevation_range_m` 등을 raw feature로 추가하는 방향을 검토 중이다. 특히 표준편차는 절대 고도보다 **구간 slope의 변동성**을 보는 것이 러닝 난이도 의미에 더 가깝다고 판단하고 있다. 아직 구현 전이다.

> [!info] 빠른 위치 파악
> - **상태:** 현재 구현

> - **역할:** 서로 단위가 다른 raw feature를 비교 가능한 적합도 점수로 바꾸고 최종 후보 순위를 만들 준비를 한다.
> - **이전 단계:** [[INDEX]]
> - **다음 단계:** [[02. Raw Feature와 Sub-score]]
> - **주요 입력:** cand + feature profiles
> - **주요 출력:** scored cand

## score_candidate()

현재 한 후보에 대해:

```python
subs = compute_sub_scores(cand)
failed, exact = check_requirements(cand, requirements)

cand["sub_scores"] = subs
cand["condition_score"] = compute_condition_score(subs, weights)
cand["failed_conditions"] = failed
cand["exact_match"] = exact
cand["estimated_minutes"] = ...
```

을 수행한다.

## 세 종류의 의미를 구분

```text
Raw Feature
= 측정된 사실
예: park_ratio=0.08

Sub-score
= 서비스 heuristic 기준으로 0~100 변환
예: park=53.3

Condition Score
= 사용자가 중요하게 보는 항목 weight를 반영한 가중평균
```

문서에서는 일반적인 “점수”보다 **적합도 점수(suitability score)**라고 해석하는 것이 정확하다.

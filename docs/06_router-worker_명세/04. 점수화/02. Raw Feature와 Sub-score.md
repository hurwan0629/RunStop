# Raw Feature와 Sub-score

> [!info] 빠른 위치 파악
> - **상태:** 현재 구현
> - **소스 위치:** `routing-worker/src/algo/scoring/weighting.py::compute_sub_scores`
> - **역할:** 각 raw feature가 어떤 sub-score로 변환되는지 현재 구현을 항목별로 정리한다.
> - **이전 단계:** [[01. 점수화 전체 흐름]]
> - **다음 단계:** [[03. Weighting 상수와 기준]]
> - **주요 입력:** CandidateRoute raw feature
> - **주요 출력:** SubScores dict

## 공통 변환 함수

### 낮을수록 좋음

```text
good → 100
bad  → 0
사이 → 선형
밖  → 0~100 clamp
```

사용: 거리오차, 상승고도/km, 신호등/km, overlap.

### 높을수록 좋음

```text
zero → 0
full → 100
사이 → 선형
밖  → 0~100 clamp
```

사용: 공원/하천 비율, 조명/CCTV 밀도, walkable ratio 등.

## 현재 sub-score

| Sub-score | Raw input | 방향 |
|---|---|---|
| distance | `distance_error_pct` | 낮을수록 좋음 |
| elevation | `elevation_gain_m / km` | 낮을수록 좋음 |
| toilet | count + nearest | 많고 가까울수록 좋음 |
| store | count + nearest | 많고 가까울수록 좋음 |
| park | `park_ratio` | 높을수록 좋음 |
| water | `water_ratio` | 높을수록 좋음 |
| streetlight | `(light+security+walklight)/km` | 높을수록 좋음 |
| cctv | `cctv_count/km` | 높을수록 좋음 |
| surface | walkable 기반 - bigroad - stairs | 높을수록 좋음 |
| flow | `signal_per_km` | 낮을수록 좋음 |
| overlap | `overlap_ratio` | 낮을수록 좋음 |

`out_and_back`은 구조상 overlap이 필수이므로 overlap sub-score를 `None`으로 제외한다.

# Weighting 상수와 기준

> [!info] 빠른 위치 파악
> - **상태:** 현재 구현
> - **소스 위치:** `routing-worker/src/algo/scoring/weighting.py`
> - **역할:** 0점/100점 기준과 시설/노면 penalty 등 현재 heuristic 상수들을 한곳에 기록한다.
> - **이전 단계:** [[02. Raw Feature와 Sub-score]]
> - **다음 단계:** [[04. 사용자 Weight 가중평균]]
> - **주요 입력:** 현재 weighting.py 상수
> - **주요 출력:** 현재 점수화 기준

> [!warning] 해석
> 아래 값은 **현재 코드의 기준값**이지, 사용자 데이터나 실험으로 검증된 최적값이라는 근거가 현재 소스에 있는 것은 아니다. 추후 튜닝 예정이다.

| 상수 | 현재 값 | 의미 |
|---|---:|---|
| `DIST_ERR_ZERO_PCT` | 10% | 거리오차 10%에서 0점 |
| `GAIN_PER_KM_ZERO` | 30m/km | 이 상승고도 밀도에서 elevation 0점 |
| `ELEVATION_NEUTRAL` | 50 | DEM 결측 시 중립 |
| `TOILET_FULL` | 2 | 화장실 개수점 만점 기준 |
| `STORE_FULL` | 3 | 편의점 개수점 만점 기준 |
| `NEAR_OK_M` | 100m | 시설 최근접 감점 시작 거리 |
| `NEAR_PENALTY_SPAN_M` | 100m | 추가 거리 감점 단위 |
| `NEAR_PENALTY_PER_SPAN` | 20 | span당 감점 |
| `NEAR_PENALTY_MAX` | 40 | 시설 최근접 감점 상한 |
| `PARK_RATIO_FULL` | 0.15 | 공원 인접률 15%에서 100 |
| `WATER_RATIO_FULL` | 0.15 | 하천 인접률 15%에서 100 |
| `STREETLIGHT_PER_KM_FULL` | 120/km | 조명 100점 기준 |
| `CCTV_PER_KM_FULL` | 15/km | CCTV 100점 기준 |
| `WALKABLE_FULL` | 0.60 | walkable 기본점 100 기준 |
| `BIGROAD_ZERO` | 0.30 | 큰길 감점 scale 기준 |
| `BIGROAD_PENALTY_MAX` | 40 | 큰길 최대 감점 |
| `STAIRS_PENALTY` | 15 | 계단 segment당 감점 |
| `SIGNAL_PER_KM_ZERO` | 4/km | 신호 4/km에서 0점 |
| `OVERLAP_ZERO` | 0.30 | overlap 0.30에서 0점 |
| `PACE_MIN_PER_KM` | 6 min/km | 예상시간 계산용 고정 pace |
| `DEFAULT_WEIGHT` | 3 | 미지정 항목 fallback |

필수조건 측 별도 현재 값:

```text
DIST_TOLERANCE_PCT = 10%
REQ_MIN_COUNT = 1
REQ_PARK_RATIO_MIN = 0.05
```

> [!note] 예정
> 실제 후보 feature 분포와 사용자 선택 데이터를 확보한 뒤 이 기준값들을 재설계하는 것이 예정되어 있다.

# condition_score와 결과값

> [!info] 빠른 위치 파악
> - **상태:** 현재 구현
> - **소스 위치:** `routing-worker/src/algo/scoring/weighting.py, routing-worker/src/algo/pipeline.py`
> - **역할:** 점수화가 CandidateRoute에 추가하는 값과 현재 최종 Top-K 선택 방식을 정리한다.
> - **이전 단계:** [[05. Requirements 최종 검사]]
> - **다음 단계:** [[07. 현재 한계점]]
> - **주요 입력:** sub_scores, weights, requirements, actual_distance_m
> - **주요 출력:** scored CandidateRoute + Top-K

## 추가 필드

```python
cand["sub_scores"] = subs
cand["condition_score"] = ...
cand["failed_conditions"] = ...
cand["exact_match"] = ...
cand["estimated_minutes"] = ...
```

예상시간은 현재:

```python
round(actual_distance_km * 6.0)
```

으로 계산한다.

## 현재 최종 정렬

모든 candidate에 feature/scoring을 붙인 뒤:

```python
cands.sort(
    key=lambda c: c["condition_score"],
    reverse=True
)

return cands[:top_k]
```

기본 `top_k=3`.

즉 현재는:

```text
candidate pool 최대 8
→ 8개 모두 feature
→ 8개 모두 heuristic scoring
→ condition_score 정렬
→ Top 3
```

이다.

> [!note] AI 도입 후 예정
> AI ranking이 구현되면 이 순서는 바뀔 수 있다. 아직 현재 코드는 변경하지 않았다.

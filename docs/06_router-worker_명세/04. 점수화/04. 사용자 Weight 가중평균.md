# 사용자 Weight 가중평균

> [!info] 빠른 위치 파악
> - **상태:** 현재 구현
> - **소스 위치:** `routing-worker/src/algo/scoring/weighting.py::compute_condition_score`
> - **역할:** 각 sub-score에 사용자 weight를 적용해 하나의 condition_score를 만든다.
> - **이전 단계:** [[03. Weighting 상수와 기준]]
> - **다음 단계:** [[05. Requirements 최종 검사]]
> - **주요 입력:** SubScores, Weights
> - **주요 출력:** condition_score

## 현재 fallback weight

```python
_DEFAULT_W = {
    "distance": 3,
    "elevation": 3,
    "toilet": 3,
    "store": 3,
    "park": 3,
    "night": 3,
    "surface": 2,
    "flow": 2,
    "overlap": 2,
}
```

사용자 값이 있으면 덮어쓴다.

```python
w = {**_DEFAULT_W, **(weights or {})}
```

## weight 공유

```text
water       → park weight
streetlight → night weight
cctv        → night weight
```

## 식

`None`이 아닌 sub-score들만:

\[
condition\_score =
\frac{\sum score_i \cdot weight_i}
{\sum weight_i}
\]

로 계산한다.

## 경로 생성 weight와의 차이

같은 사용자 `weights`가 쓰이지만 계산은 다르다.

```text
경로 생성:
0~5 → 0~1 정규화 → edge cost penalty 강도

최종 점수:
0~5 값을 그대로 sub-score 가중평균 weight로 사용
```

> [!warning]
> `_DEFAULT_W`와 `config.PREFERENCE_LEVEL_DEFAULT=3`은 모두 “기본값”처럼 보이지만 적용 위치와 의미가 다르다.

> [!note] 예정
> 전체 사용자 population prior → 개인 profile → 현재 요청의 구조로 weight를 만드는 방향은 검토 중이나 아직 구현되지 않았다.

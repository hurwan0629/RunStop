# Edge Cost와 사용자 Weight

> [!info] 빠른 위치 파악
> - **상태:** 현재 구현
> - **소스 위치:** `routing-worker/src/algo/scoring/edge_cost.py`
> - **역할:** NetworkX가 edge를 탐색할 때 호출할 비용 callback을 만들고 사용자 선호/도로 속성을 비용에 반영한다.
> - **이전 단계:** [[10. Shortest Path]]
> - **다음 단계:** [[12. Requirements와 Constraint]]
> - **주요 입력:** G, weights, requirements, used_edges, reuse_factor
> - **주요 출력:** calculate_edge_cost(u,v,edge_payload) callback

## callback 생성

```python
edge_cost = create_edge_cost_function(...)
```

내부에서 요청별 값들을 기억하는 closure를 반환한다.

```text
NetworkX가 edge 확인
      ↓
calculate_edge_cost(u, v, edge_payload)
      ↓
평행 edge별 _single_edge_cost()
      ↓
허용된 cost 중 최소
```

## 현재 큰 비용 구조

\[
Cost(e) = Length(e) \times Multiplier(e)
\]

개념적으로 multiplier는:

```text
distance_priority

+ elevation_scale × elevation_weight × slope_penalty
+ safety_scale    × safety_weight    × safety_penalty
+ nature_scale    × nature_weight    × nature_penalty
+ surface_scale   × surface_weight   × surface_penalty
+ flow_scale      × flow_weight      × flow_penalty
```

이미 사용한 edge이면 마지막에 reuse multiplier를 추가 적용한다.

## 사용자 weight

사용자 입력 `0~5`를 `normalize_preference_weight()`가 `0~1`로 선형 변환한다.

```text
0 → 0.0
3 → 0.6
5 → 1.0
```

현재 alias:

```text
safety ← safety 또는 night
nature ← nature 또는 park
```

## 현재 고정 scale

| 요소 | scale |
|---|---:|
| elevation | 1.2 |
| safety | 0.8 |
| nature | 0.6 |
| surface | 0.8 |
| flow | 0.5 |

distance는 별도로:

```python
distance_priority = 0.5 + normalized_distance_weight
```

이므로 범위가 `0.5~1.5`다.

## penalty 값의 현재 범위

- slope: `2%` 이하 0, `10%` 이상 1, 사이는 선형
- safety: lit=yes → 0, lit=no → 1, unknown → 0.5
- nature: 관련 OSM tag 있음 → 0, 없음 → 0.5
- surface: steps/major=1, poor surface=0.8, walkable=0, 기타=0.4
- flow: signal=1, crossing=0.5, 일반=0

> [!note]
> 이 값들은 현재 알고리즘의 **고정 heuristic**이다. 사용자는 “요소의 중요도”를 weight로 조절하지만 “10% 경사는 얼마나 나쁜가” 같은 penalty 기준 자체를 직접 바꾸는 구조는 아니다.

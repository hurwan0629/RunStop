# _build와 RouteMode

> [!info] 빠른 위치 파악
> - **상태:** 현재 구현
> - **소스 위치:** `routing-worker/src/algo/routing/course.py`
> - **역할:** 일반 경로에서 RouteMode별로 waypoint와 shortest path 조립 방법을 결정한다.
> - **이전 단계:** [[05. Via Course 생성 - generate_course_via]]
> - **다음 단계:** [[07. _route_chain과 Via 연결]]
> - **주요 입력:** mode, start/end, scale, bearing, weights, requirements
> - **주요 출력:** (NodePath, 실제 거리 m)

## out_and_back

```text
S → W
W → S는 첫 path를 정확히 역순 복사
```

```python
out, out_len = shortest_path(...)
return out + out[-2::-1], out_len * 2
```

따라서 구조적으로 overlap이 큰 것이 정상이다.

## loop

```text
S → W : shortest_path
W → S : 첫 구간 edge들에 LOOP penalty를 주고 다시 shortest_path
```

목표는 같은 길 그대로 복귀하는 것을 억제해 순환형 경로를 만드는 것이다.

## point_to_point

```text
S → W → E
```

`W`는 start/end를 초점으로 하는 타원 위 8개 점 중 두 초점을 잇는 선분에 수직인 측면 점을 선택한다. 현재는 index `2` 또는 `6`을 사용하고, bearing은 두 측면 중 어느 쪽을 쓸지 고르는 데만 사용한다.

첫 구간의 edge를 두 번째 구간에 P2P 재사용 penalty로 전달한다.

> [!tip]
> `_build`는 “여러 anchor를 잇는 범용 함수”가 아니라 **mode별 코스 모양을 알고 있는 함수**다.

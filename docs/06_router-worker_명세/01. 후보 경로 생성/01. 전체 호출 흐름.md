# 후보 경로 생성 전체 호출 흐름

> [!info] 빠른 위치 파악
> - **상태:** 현재 구현
> - **소스 위치:** `routing-worker/src/algo/pipeline.py`
> - **역할:** `recommend()`에서 후보 생성 계층으로 진입하는 조건과 일반/Via 분기를 보여준다.
> - **이전 단계:** [[INDEX]]
> - **다음 단계:** [[02. 일반 후보 생성 - generate_candidates]]
> - **주요 입력:** route_type, start, target_km, end, vias, weights, requirements
> - **주요 출력:** cands

## recommend의 앞부분

```python
mode = _MODE.get(route_type)
if mode is None:
    raise ValueError(...)

if mode == "point_to_point" and end is None:
    raise ValueError(...)

target_m = target_km * 1000
```

이후 `vias` 존재 여부가 첫 분기다.

```python
if vias:
    cands = generate_candidates_via(...)
else:
    cands = generate_candidates(...)
```

## 의미

`recommend()`은 경로를 직접 만들지 않는다.

```text
recommend
= orchestration / pipeline entry

candidates
= 여러 방향에서 후보를 만드는 계층

course
= 특정 방향의 코스 하나를 만드는 계층

shortest_path
= 두 node 사이 실제 Graph 탐색
```

`weights`와 `requirements`는 후보 생성기부터 shortest path까지 그대로 내려간다.

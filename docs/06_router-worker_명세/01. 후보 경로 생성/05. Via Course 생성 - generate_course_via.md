# Via Course 생성 - generate_course_via

> [!info] 빠른 위치 파악
> - **상태:** 현재 구현
> - **소스 위치:** `routing-worker/src/algo/routing/course.py`
> - **역할:** 여러 사용자 지정 Via를 순서대로 반드시 통과하고, 부족한 목표거리는 마지막 구간 우회점으로 보정한다.
> - **이전 단계:** [[04. Course 생성 - generate_course]]
> - **다음 단계:** [[06. _build와 RouteMode]]
> - **주요 입력:** mode, start, vias[], target_distance_m, end(optional), bearing, weights, requirements
> - **주요 출력:** mode="via" CandidateRoute

## 1. mode 분기

`mode == "out_and_back"`이면 `_generate_out_and_back_via()`로 넘긴다.

```text
S → V1 → V2
V2 → V1 → S
```

이 경우 복귀 구간은 outbound path를 역순으로 붙여 동일 경로 복귀를 보장한다.

## 2. anchor chain 생성

```python
tail = end if end is not None else start
anchors = [start] + list(vias) + [tail]
anchor_nodes = [idx.snap(*a) for a in anchors]
```

예:

```text
S → V1 → V2 → S
```

또는 ONE_WAY:

```text
S → V1 → V2 → E
```

## 3. 일단 최소 chain을 연결

```python
fixed_nodes, fixed_len = _route_chain(...)
```

- 이미 목표거리보다 `1 + tol` 이상 길면 실패
- 이미 목표거리의 `1 - tol` 이상이면 그대로 반환
- 너무 짧으면 마지막 구간에 우회점 `P`를 추가

```text
... → 마지막 Via → P → Tail
```

`P`는 마지막 Via와 Tail을 두 초점으로 하는 타원 위 점이다.

## 4. 우회 scale 반복 보정

```python
scale = direct_distance(last_via, tail)
      + (target_distance - fixed_len)
```

로 시작하고, 일반 course와 유사하게 damping된 `target / actual` 비율로 반복 보정한다.

> [!note]
> 여러 Via 자체는 모두 유지된다. 거리 부족분을 채우는 우회점은 현재 마지막 구간에 하나만 삽입한다.

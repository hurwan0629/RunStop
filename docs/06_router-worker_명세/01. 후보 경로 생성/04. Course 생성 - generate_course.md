# Course 생성 - generate_course

> [!info] 빠른 위치 파악
> - **상태:** 현재 구현
> - **소스 위치:** `routing-worker/src/algo/routing/course.py`
> - **역할:** 특정 mode와 bearing 하나에 대해 목표거리에 가까운 코스 한 개를 만든다.
> - **이전 단계:** [[03. Via 후보 생성 - generate_candidates_via]]
> - **다음 단계:** [[05. Via Course 생성 - generate_course_via]]
> - **주요 입력:** mode, start/end, target_distance_m, bearing, weights, requirements
> - **주요 출력:** CandidateRoute 1개

## 역할

`generate_candidates()`가 방향을 여러 개 돌린다면 `generate_course()`는 **그중 한 방향의 후보 한 개**를 책임진다.

## 초기 scale

```python
scale = (
    target_distance_m / 2
    if mode in ("loop", "out_and_back")
    else target_distance_m
)
```

그 뒤 `_build()`로 실제 경로를 만들고, 실제 거리 오차를 측정한다.

```text
초기 scale
  ↓
_build()
  ↓
실제 Graph 경로 거리 dist
  ↓
목표거리와 비교
  ↓
scale feedback
  ↓
반복
```

기본 최대 반복은 6회, `5%` 이내면 조기 종료한다.

반복 중 가장 오차가 작은 `(nodes, dist, scale)`을 `best`로 저장하고 마지막에 `_pack()`으로 CandidateRoute를 만든다.

# Candidate Pool 필터링

> [!info] 빠른 위치 파악
> - **상태:** 현재 구현
> - **소스 위치:** `routing-worker/src/algo/routing/candidates.py`
> - **역할:** 생성된 여러 course에서 거리/겹침/유사성이 지나친 후보를 제거해 Feature 단계의 후보 pool을 만든다.
> - **이전 단계:** [[13. 거리 Scale 보정]]
> - **다음 단계:** [[15. 현재 한계점]]
> - **주요 입력:** bearing별 CandidateRoute
> - **주요 출력:** 최대 8개 CandidateRoute

## 일반 후보 하드컷

```text
CAND_DIST_TOL_PCT = 10%
CAND_MAX_OVERLAP  = 0.35
```

`out_and_back`은 구조적으로 같은 길을 돌아오기 때문에 overlap hard-cut에서 제외한다.

## 중복 후보 제거

두 후보의 방향 무시 edge set:

```python
Ea = path_to_edge_set(a_nodes)
Eb = path_to_edge_set(b_nodes)
```

에 대해:

```text
공유율 =
|Ea ∩ Eb| / min(|Ea|, |Eb|)
```

가 `DEDUP_SIMILARITY=0.6`을 초과하면 같은 코스로 취급해 뒤 후보를 제거한다.

## pool

중복 제거 후:

```python
[:pool]   # 기본 8
```

# Via 후보 생성 - generate_candidates_via

> [!info] 빠른 위치 파악
> - **상태:** 현재 구현
> - **소스 위치:** `routing-worker/src/algo/routing/candidates.py`
> - **역할:** 사용자가 반드시 통과할 vias를 지정했을 때 여러 bearing의 Via course 후보를 만든다.
> - **이전 단계:** [[02. 일반 후보 생성 - generate_candidates]]
> - **다음 단계:** [[04. Course 생성 - generate_course]]
> - **주요 입력:** start, vias[], target_m, end, mode, n_directions, weights, requirements
> - **주요 출력:** 최대 pool=8 Via CandidateRoute

## end 처리

```python
tail = end if mode == "point_to_point" else None
```

즉:

```text
ONE_WAY + Via
→ 마지막은 end

LOOP + Via
→ end=None → generate_course_via에서 start 복귀

ROUND_TRIP + Via
→ end=None → generate_course_via에서 동일 경로 역순 복귀
```

## 후보 반복

각 bearing마다:

```python
generate_course_via(
    G, idx, mode, start, vias, target_m,
    end=tail,
    bearing=...,
    weights=weights,
    requirements=requirements,
)
```

를 호출한다.

현재 Via 후보의 거리 필터는 코드 내부에 `<= 10`으로 직접 들어가 있다.

```python
if r["distance_error_pct"] <= 10:
    out.append(r)
```

그 뒤 overlap / distance error 정렬 → near-duplicate 제거 → pool 최대 8개다.

> [!note]
> `ROUND_TRIP+Via`는 `mode`를 전달해 `_generate_out_and_back_via()`에서 따로 처리한다. 최종 CandidateRoute의 `mode` 값은 기존처럼 `"via"`로 pack된다.

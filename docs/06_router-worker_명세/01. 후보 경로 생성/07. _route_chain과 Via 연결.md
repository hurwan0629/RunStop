# _route_chain과 Via 연결

> [!info] 빠른 위치 파악
> - **상태:** 현재 구현
> - **소스 위치:** `routing-worker/src/algo/routing/course.py`
> - **역할:** 여러 NodeId anchor를 순서대로 shortest_path로 연결하며 이전 segment edge를 누적 penalty 처리한다.
> - **이전 단계:** [[06. _build와 RouteMode]]
> - **다음 단계:** [[08. Waypoint - 원]]
> - **주요 입력:** node_chain=[A,B,C,...], weights, requirements
> - **주요 출력:** 전체 NodePath, 총 실제 거리

## 핵심

```python
for a, b in zip(node_chain[:-1], node_chain[1:]):
    seg, seg_len = shortest_path(
        G, a, b,
        penalty_edges=used,
        factor=penalty,
        weights=weights,
        requirements=requirements,
    )
    used |= path_to_edge_set(seg)
```

예:

```text
A → B
    사용 edge 기록
B → C
    A→B에서 사용한 edge에 penalty
C → D
    앞의 모든 사용 edge에 penalty
```

`_build()`와의 차이:

```text
_build
= LOOP / ROUND_TRIP / ONE_WAY 의미를 알고 있다.

_route_chain
= mode를 모르고 전달받은 anchor를 순서대로 잇는다.
```

그래서 Via 구현에 적합하다.

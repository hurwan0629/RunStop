# Waypoint - 원

> [!info] 빠른 위치 파악
> - **상태:** 현재 구현
> - **소스 위치:** `routing-worker/src/algo/routing/waypoints.py`
> - **역할:** LOOP와 ROUND_TRIP의 방향/거리 스케일을 실제 경유 좌표로 변환한다.
> - **이전 단계:** [[07. _route_chain과 Via 연결]]
> - **다음 단계:** [[09. Waypoint - 타원]]
> - **주요 입력:** start(lat,lon), radius_m, bearing
> - **주요 출력:** 원 위 Coordinate

## 현재 구현

```python
circle_waypoints(
    lat,
    lon,
    radius_m=scale,
    n=1,
    start_bearing=bearing,
)
```

`point_at_bearing()`을 사용하므로 실제 측지선 기준으로:

```text
start + bearing + scale(m)
→ waypoint
```

을 얻는다.

일반 후보 생성에서 bearing을 여러 개 돌리므로 출발점 주변의 서로 다른 방향으로 waypoint가 이동한다.

```text
          0°
           ●
270° ●     S     ● 90°
           ●
          180°
```

> [!note]
> `n=1`이므로 한 번의 `_build()`에서는 waypoint 하나만 사용한다. 다양성은 바깥의 `generate_candidates()`가 bearing을 바꿔 확보한다.

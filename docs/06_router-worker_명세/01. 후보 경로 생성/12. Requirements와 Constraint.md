# Requirements와 Edge Constraint

> [!info] 빠른 위치 파악
> - **상태:** 현재 구현
> - **소스 위치:** `routing-worker/src/algo/scoring/constraints.py`
> - **역할:** 경로 탐색 전에 지나가면 안 되는 edge를 hard constraint로 제외한다.
> - **이전 단계:** [[11. Edge Cost와 사용자 Weight]]
> - **다음 단계:** [[13. 거리 Scale 보정]]
> - **주요 입력:** edge_data, requirements
> - **주요 출력:** 위반 여부 bool → edge cost None

## 현재 edge-level hard constraint

### 계단 금지

```python
if required.get("no_stairs") and "steps" in highway_tags:
    return True
```

### 최대 경사

지원 key:

```text
max_slope_pct
max_slope
maxSlope
```

edge의 `grade_abs` 또는 `grade`를 퍼센트로 바꾸어 기준을 초과하면 위반이다.

## Dijkstra에서의 의미

위반 edge는 큰 숫자를 반환하는 것이 아니라 최종적으로 `None` cost가 되어 탐색 대상에서 빠진다.

```text
requirement 위반
→ edge cost = None
→ NetworkX 탐색에서 제외
```

> [!warning]
> 해당 edge에 slope 데이터 자체가 없으면 max slope 요구가 있어도 현재는 통과한다. 데이터 결측을 “위반”으로 보지 않는 정책이다.

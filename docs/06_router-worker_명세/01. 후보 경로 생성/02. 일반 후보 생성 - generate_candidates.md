# 일반 후보 생성 - generate_candidates

> [!info] 빠른 위치 파악
> - **상태:** 현재 구현
> - **소스 위치:** `routing-worker/src/algo/routing/candidates.py`
> - **역할:** Via가 없는 요청에서 여러 bearing으로 course를 만들어 후보 pool을 구성한다.
> - **이전 단계:** [[01. 전체 호출 흐름]]
> - **다음 단계:** [[03. Via 후보 생성 - generate_candidates_via]]
> - **주요 입력:** G, idx, mode, start, target_distance_m, end, n_directions=12, weights, requirements
> - **주요 출력:** 최대 pool=8 CandidateRoute

## 방향 반복

기본 `n_directions=12`이면:

```text
0°, 30°, 60°, 90°, ... , 330°
```

를 각각 시도한다.

```python
for k in range(n_directions):
    bearing = 360.0 * k / n_directions
    r = generate_course(
        G, idx, mode, start, target_distance_m,
        end=end,
        bearing=bearing,
        weights=weights,
        requirements=requirements,
    )
```

한 방향에서 경로 생성이 실패하면 전체 요청을 중단하지 않고 그 방향만 건너뛴다.

```python
except (ValueError, nx.NetworkXException):
    continue
```

## 1차 통과 조건

```python
distance_error_pct <= CAND_DIST_TOL_PCT
```

그리고 `out_and_back`이 아니라면:

```python
overlap_ratio <= CAND_MAX_OVERLAP
```

을 추가로 요구한다.

최종적으로 overlap → distance error 순으로 정렬하고, 비슷한 후보를 제거한 뒤 최대 8개만 남긴다.

> [!note]
> 여기서 자르는 8개는 **Final Top-K가 아니라 Feature/Scoring으로 넘길 candidate pool**이다.

# 공원 및 하천 GeoJSON

> [!info] 빠른 위치 파악
> - **상태:** 현재 구현
> - **소스 위치:** `사용자 제공 fetch_park_water.py / build_osm_layers.py`
> - **역할:** Nature feature가 사용하는 공원·하천 polygon을 OSMnx로 생성하는 현재 데이터 lineage를 기록한다.
> - **이전 단계:** [[03. 시설 통합 CSV]]
> - **다음 단계:** [[INDEX]]
> - **주요 입력:** OpenStreetMap features via OSMnx
> - **주요 출력:** 서울_공원.geojson, 서울_하천_polygon.geojson

## 공원

현재 OSMnx query tag:

```python
{
    "leisure": [
        "park", "garden", "recreation_ground",
        "pitch", "playground"
    ],
    "landuse": [
        "recreation_ground", "grass", "village_green"
    ],
}
```

Polygon / MultiPolygon만 남겨:

```text
서울_공원.geojson
```

으로 저장한다.

## 하천/수역

현재 tag:

```python
{
    "natural": ["water"],
    "water": True,
    "waterway": [
        "river", "stream", "canal", "riverbank"
    ],
}
```

그중 Polygon/MultiPolygon:

```text
서울_하천_polygon.geojson
```

을 Nature feature가 사용한다.

LineString/MultiLineString은 별도:

```text
서울_하천_line.geojson
```

으로 저장하지만 현재 `nature.py`의 ratio 계산은 polygon 파일을 사용한다.

## 데이터 흐름

```text
OpenStreetMap
→ OSMnx features_from_place("Seoul, South Korea")
→ EPSG:4326 GeoJSON freeze
→ nature.py에서 EPSG:5179 변환
→ route buffer와 면적 교집합
→ park_ratio / water_ratio
```

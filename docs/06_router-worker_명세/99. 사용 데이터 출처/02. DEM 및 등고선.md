# DEM 및 등고선

> [!info] 빠른 위치 파악
> - **상태:** 현재 구현
> - **소스 위치:** `routing-worker/src/algo/data/서울_DEM_10m.npy 및 메타데이터`
> - **역할:** 현재 경사 feature가 조회하는 10m DEM의 원본 등고선/좌표/해상도 정보를 기록한다.
> - **이전 단계:** [[01. OSM 및 보행 네트워크]]
> - **다음 단계:** [[03. 시설 통합 CSV]]
> - **주요 입력:** 국토교통부/국토지리정보원 계열 서울 등고선 SHP로 추정되는 원본
> - **주요 출력:** 서울_DEM_10m.npy

## 사용자가 제공한 메타데이터

```json
{
  "crs": "EPSG:5179",
  "x_min": 935192.7194999997,
  "y_min": 1936683.4549000002,
  "x_max": 972062.9226000002,

  "resolution_m": 10.0,

  "note": "row 0 = y_min(남쪽), col 0 = x_min(서쪽). elevation unit: meter",
  "source": "N3L_F0010000_11.shp (국토교통부 등고선, 서울)"
}
```

## 현재 확인된 원본 링크

https://data.edmgr.kr/dataView.do?id=vworld_open_30185

사용자가 함께 제시한 공공데이터포털 링크:

https://www.data.go.kr/data/15125058/fileData.do

## 알고리즘 사용

```text
Coordinate
→ get_elevation(lat, lon)
→ DEM 고도(m)
→ 구간 slope / elevation_gain
```

> [!warning] 미확인 범위
> 원본 `N3L_F0010000_11.shp`에서 현재 `서울_DEM_10m.npy`를 생성한 **정확한 rasterization/interpolation 변환 스크립트는 이번 문서 자료에 포함되지 않았다.**
>
> 따라서 “원본 출처와 최종 메타데이터”는 기록하되, 중간 변환 알고리즘은 확인된 것으로 쓰지 않는다.

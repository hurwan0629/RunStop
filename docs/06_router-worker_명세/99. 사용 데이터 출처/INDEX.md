# 99. 사용 데이터 출처

> [!info] 빠른 위치 파악
> - **상태:** 현재 구현
> - **소스 위치:** `routing-worker/src/algo/data 및 사용자가 제공한 원본 수집 정보`
> - **역할:** 알고리즘에서 쓰는 도로/DEM/시설/자연 데이터가 어디에서 왔고 어떤 파일로 사용되는지 기록한다.
> - **이전 단계:** [[../04. 점수화/INDEX|04. 점수화]]
> - **다음 단계:** [[../README|문서 루트]]
> - **주요 입력:** 원본 출처 URL, OSMnx 수집 스크립트, 메타데이터
> - **주요 출력:** 데이터 lineage 요약

## 현재 확인 수준

| 데이터 | 현재 사용 파일 | 출처 확인 |
|---|---|---|
| 보행 네트워크 | `서울_보행네트워크.graphml` | OSMnx 수집 스크립트 확인 |
| DEM | `서울_DEM_10m.npy` + meta | 원본 등고선 출처/메타 확인, 변환 과정 일부 미확인 |
| 시설 | `서울_시설데이터_통합.csv` | 원본 링크 일부 확인, 전체 목록은 미완성 |
| 공원 | `서울_공원.geojson` | OSMnx 수집 스크립트 확인 |
| 하천 | `서울_하천_polygon.geojson` | OSMnx 수집 스크립트 확인 |

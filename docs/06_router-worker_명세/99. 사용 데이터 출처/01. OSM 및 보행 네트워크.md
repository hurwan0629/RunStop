# OSM 및 보행 네트워크

> [!info] 빠른 위치 파악
> - **상태:** 현재 구현
> - **소스 위치:** `사용자 제공 build_osm_layers.py / routing-worker data`
> - **역할:** OSMnx를 이용해 서울 보행 Graph와 OSM 기반 부가 레이어를 동결 파일로 생성한 과정을 기록한다.
> - **이전 단계:** [[INDEX]]
> - **다음 단계:** [[02. DEM 및 등고선]]
> - **주요 입력:** OSMnx, place="Seoul, South Korea"
> - **주요 출력:** 서울_보행네트워크.graphml 및 OSM 부가 레이어

## 보행 네트워크 생성

사용자가 제공한 수집 스크립트의 핵심:

```python
PLACE = "Seoul, South Korea"

G = ox.graph_from_place(
    PLACE,
    network_type="walk",
    simplify=True,
)

ox.save_graphml(
    G,
    ".../서울_보행네트워크.graphml"
)
```

따라서 현재 보행 Graph의 계보는:

```text
OpenStreetMap
→ OSMnx graph_from_place(network_type="walk")
→ 서울_보행네트워크.graphml
→ utils.graph.load_graph()
→ G
```

## 같은 스크립트의 추가 추출

- `highway=steps` 계단
- `street_count>=3` 교차로
- `highway=crossing` 횡단보도
- `leisure/landuse` 기반 공원
- `natural/water/waterway` 기반 하천

수집 출력은 EPSG:4326이고, 알고리즘에서 거리/면적 계산이 필요한 경우 EPSG:5179로 투영한다.

## 수집 원본

- OpenStreetMap
- 수집 라이브러리: OSMnx

> [!note]
> 이 문서는 데이터 다운로드 시점의 OSM 상태를 실시간 조회하는 것이 아니라, 프로젝트가 **한 번 수집 후 freeze한 로컬 파일**을 사용하는 현재 방식을 설명한다.

# NodePath, EdgeKey, EdgeSet

> [!info] 빠른 위치 파악
> - **상태:** 현재 구현
> - **소스 위치:** `routing-worker/src/algo/types.py, routing-worker/src/algo/routing/shortest_path.py`
> - **역할:** 경로를 node 열로 표현하고, 중복/재사용 판단을 위해 edge를 방향 무시 집합으로 표현한다.
> - **이전 단계:** [[03. NodeIndex]]
> - **다음 단계:** [[05. RouteType과 RouteMode]]
> - **주요 입력:** NodeId 목록
> - **주요 출력:** NodePath / EdgeKey / EdgeSet

## 타입

```python
NodeId: TypeAlias = object
NodePath: TypeAlias = list[NodeId]
EdgeKey: TypeAlias = frozenset[NodeId]
EdgeSet: TypeAlias = set[EdgeKey]
```

예:

```text
NodePath = [A, B, C, D]

path_to_edge_set(NodePath)
= {
    {A,B},
    {B,C},
    {C,D}
  }
```

`frozenset((u,v))`를 사용하기 때문에 `A→B`와 `B→A`를 같은 edge 재사용으로 본다.

현재 사용처:

- LOOP 복귀 경로 재사용 penalty
- P2P/Via segment 재사용 penalty
- Candidate overlap 계산
- 서로 비슷한 후보 deduplication

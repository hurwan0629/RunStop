# NodeIndex

> [!info] 빠른 위치 파악
> - **상태:** 현재 구현
> - **소스 위치:** `routing-worker/src/algo/utils/graph.py`
> - **역할:** 사용자가 준 위경도를 실제 도로 그래프의 가장 가까운 node id로 스냅한다.
> - **이전 단계:** [[02. G - MultiDiGraph]]
> - **다음 단계:** [[04. NodePath EdgeSet EdgeKey]]
> - **주요 입력:** G, (lat, lon)
> - **주요 출력:** NodeId

## 생성

`G`의 모든 node를 EPSG:5179로 투영하고 `scipy.spatial.cKDTree`를 만든다.

```python
self.ids = list(G.nodes)
xy = np.array([
    to_5179.transform(G.nodes[n]["x"], G.nodes[n]["y"])
    for n in self.ids
])
self._tree = cKDTree(xy)
```

## snap

```python
def snap(self, lat, lon):
    x, y = to_5179.transform(lon, lat)
    _, i = self._tree.query([x, y])
    return self.ids[i]
```

```text
사용자 GPS
   ↓ EPSG:5179
(x, y)
   ↓ KD-tree nearest neighbor
가장 가까운 G node id
```

> [!note]
> NodeIndex는 경로 탐색 알고리즘이 아니다. **좌표 → 그래프 node id 연결용 인덱스**다.

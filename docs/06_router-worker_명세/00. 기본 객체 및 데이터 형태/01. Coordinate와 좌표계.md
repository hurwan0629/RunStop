> - **역할:** 외부 위경도 표현과 거리/면적 계산용 좌표계를 구분한다.
> - **이전 단계:** [[INDEX]]
> - **다음 단계:** [[02. G - MultiDiGraph]]
> - **주요 입력:** 위도/경도
> - **주요 출력:** Coordinate, EPSG:4326 ↔ EPSG:5179 변환

## Coordinate

현재 타입 정의:

```python
Coordinate: TypeAlias = tuple[float, float]
```

알고리즘 외부/내부에서 위경도 좌표쌍은 다음 순서를 사용한다.

```text
Coordinate = (latitude, longitude)
           = (위도, 경도)
```

예:

```python
start = (37.571806, 127.011287)
```

## 좌표계 역할

| 용도 | 좌표계 | 이유 |
|---|---|---|
| API, 지도 표시, OSM node 좌표 | EPSG:4326 | 일반 위경도 |
| buffer, 면적, KD-tree 등 미터 단위 공간 연산 | EPSG:5179 | 한국 지역 미터 좌표 |

`pyproj.Transformer(..., always_xy=True)`를 사용하므로 변환기 호출은 `(lon, lat)` 순서다.

```python
x, y = to_5179.transform(lon, lat)
lon, lat = to_4326.transform(x, y)
```

> [!warning] 순서 혼동 주의
> `Coordinate` 자체는 `(lat, lon)`이지만 Transformer 입력은 `(lon, lat)`이다.

## 거리/방위

- `haversine_m(a, b)` → 두 Coordinate 사이 지표면 거리(m)
- `point_at_bearing(lat, lon, bearing_deg, distance_m)` → 특정 방위/거리의 새 Coordinate
- bearing은 **북=0°, 시계방향**이다.

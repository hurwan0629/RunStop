# RouteType과 RouteMode

> [!info] 빠른 위치 파악
> - **상태:** 현재 구현
> - **소스 위치:** `routing-worker/src/algo/types.py, routing-worker/src/algo/pipeline.py`
> - **역할:** 외부 API 경로 종류를 내부 course 생성 모드로 변환한다.
> - **이전 단계:** [[04. NodePath EdgeSet EdgeKey]]
> - **다음 단계:** [[06. Weights와 Requirements]]
> - **주요 입력:** LOOP / ONE_WAY / ROUND_TRIP
> - **주요 출력:** loop / point_to_point / out_and_back

## 매핑

```python
_MODE = {
    "LOOP": "loop",
    "ONE_WAY": "point_to_point",
    "ROUND_TRIP": "out_and_back",
}
```

| RouteType | RouteMode | 현재 의미 |
|---|---|---|
| `LOOP` | `loop` | 다른 길로 돌아오는 순환형 |
| `ONE_WAY` | `point_to_point` | start → waypoint → end |
| `ROUND_TRIP` | `out_and_back` | 갔던 path를 역순으로 그대로 복귀 |

`ONE_WAY`는 `end`가 없으면 `recommend()`에서 즉시 `ValueError`가 발생한다.

> [!warning] Via 사용 시
> Via 경로는 최종 CandidateRoute에 `mode="via"`로 pack된다. 다만 `generate_course_via()`는 원래 `RouteMode`를 입력으로 받아 `ROUND_TRIP+Via`일 때 `_generate_out_and_back_via()`로 분기한다.
>
> 따라서 `ROUND_TRIP+Via`는 나간 경로를 역순으로 돌아오고, `LOOP+Via`는 기존처럼 start 복귀 chain을 구성한다.

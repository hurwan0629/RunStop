1. 기본 정보

알고리즘 문서의 식별 정보와 담당 범위를 기록합니다.

2. 입출력 JSON

string, number, boolean, object, array, null을 지원하며 object/array는 계속 중첩할 수 있습니다.

3. 알고리즘 구조

단계를 추가하면 번호가 자동으로 붙습니다. 제목 행을 눌러 내용을 열고 닫을 수 있습니다.

4. 사용하는 데이터

이름과 위치는 짧게, 사용 목적은 넓게 작성할 수 있도록 비율을 나눴습니다.

5. 예외 및 오류 발생 가능 지점

발생 지점·조건·오류·처리 방식을 한 줄 비율형 레이아웃으로 작성하고 필요할 때만 펼칩니다.

6. 전제조건 / 제약사항

좌표계, 단위, 필수값, 지원 범위, 처리 제한 등을 작성합니다.

7. 의존성

이름·버전은 좁게, 용도는 넓게 작성합니다.

8. 테스트 케이스

코드를 직접 작성하거나 파일에서 읽어올 수 있고, 별도 저장소·Notebook·테스트 파일 링크도 기록할 수 있습니다.

이 HTML은 코드를 직접 실행하지 않습니다. 실제 실행 입력/출력, stderr, Exit Code, 실행 시간을 기록하는 용도입니다.
JSON 메타데이터에는 DTO 트리, 알고리즘 단계, 데이터, 예외, 의존성, 테스트 코드와 링크가 함께 저장됩니다.

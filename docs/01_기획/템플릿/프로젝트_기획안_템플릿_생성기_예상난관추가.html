AI 서비스 기획서 템플릿

1. 프로젝트 개요 및 추진 배경

해결하려는 문제, 서비스가 필요한 배경, 주요 사용자와 목표를 중심으로 작성하세요.

2. 기존 서비스와의 차별점과 흥미를 끌 요소

기존 방식의 한계와 우리 서비스만의 차별점, 사용자가 ‘써보고 싶다’고 느낄 요소를 함께 작성하세요.

3. 서비스 플로우

기술 흐름이 아니라 실제 사용자의 시점에서 ‘무엇을 입력하고 → 무엇을 확인하고 → 무엇을 선택하는지’ 작성하세요.

서비스 사용 화면, 사용자 사용 장면 또는 서비스 플로우 이미지를 넣을 수 있습니다.

4. 예상 난관

데이터 확보, 모델 성능, 기술 구현, 사용자 경험 등 프로젝트 진행 과정에서 예상되는 어려움과 대응 방향을 작성하세요.

5. 활용 데이터

학습용 입력 변수(Feature)와 정답(Label/Target)을 구성하는 데이터셋을 자료 단위로 추가하세요.

6. 해당 주제를 진행하기 위한 근거 자료

변수 간 관계, 예측 가능성, 선행연구, 통계/논문 등 ‘왜 이 주제가 성립하는가’를 뒷받침하는 자료를 추가하세요.

내보내기: “PDF 저장”은 브라우저 인쇄 창을 열며, Chrome/Edge에서 대상 프린터를 PDF로 저장으로 선택하면 업로드한 이미지까지 포함됩니다. “폴더묶음 ZIP”은 작성 내용, 보고서 HTML, 이미지 원본, JSON 데이터를 하나의 ZIP으로 묶습니다.

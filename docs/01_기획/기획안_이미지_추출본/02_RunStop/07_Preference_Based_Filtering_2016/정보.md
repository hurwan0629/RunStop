## 내용

해당 논문은 러닝 경로를 세 종류의 특징으로 나눠서 설명합니다. Performance Features: 거리, 고도 변화. Visual Features: 공원과 가까운지, 물가/호수와 가까운지. Nature of Route: 트랙인지, 도로인지/비포장인지, 출발점과 도착점이 같은 순환형인지.

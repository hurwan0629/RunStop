## 과채류 외관 신선도 비교 AI 서비스

### 서비스 예상 사용 화면

마트에서 과채류를 구매할 때 카메라로 진열대를 비추면, AI가 과채류의 종류와 외관 기반 신선도(Visual Freshness)를 판단하여 상대적으로 상태가 좋은 개체를 선택할 수 있도록 돕는 서비스다.

**링크**
- 없음 (PDF 내 별도 링크 없음)
- 폴더: `05_과채류_외관_신선도_비교_AI_서비스/01_서비스_예상_사용_화면`
- 이미지: 1개

### AgriFreshNET Freshness and Shelf-Life Image Dataset

약 14,500장의 RGB 이미지와 24개 과채류 class로 구성되며, 실제 시장·슈퍼마켓·가정·농장·저장시설 등에서 스마트폰으로 촬영된 데이터다. 신선도 단계는 Fresh / Semi-Fresh / Rotten이며 품목별 대략적인 post-harvest shelf-life annotation도 제공한다. 데이터 형태: RGB Image + Produce Class + Freshness Stage + Approximate Shelf-life. 데이터 설명에는 개별 객체의 Bounding Box annotation이 명확히 제시되어 있지 않으므로, 여러 과채류를 동시에 탐지하는 기능에는 별도의 Detection 데이터 또는 직접 Bounding Box annotation이 필요할 수 있다.

**링크**
- https://data.mendeley.com/datasets/42m5tb7yv9/1
- 폴더: `05_과채류_외관_신선도_비교_AI_서비스/02_AgriFreshNET_데이터셋`
- 이미지: 1개

### Fruits and Vegetables Freshness Categorization Using Deep Learning

과채류의 색(color), 질감(texture), 크기(size), 형태(shape)와 같은 외관 특징을 이용하여 신선도를 분류한 연구다. 11종의 과일·채소, 총 60,059장의 이미지를 Pure-Fresh / Medium-Fresh / Rotten 세 단계로 구분하고 VGG-16과 YOLO-v5를 적용했다. 특히 일부 이미지는 한 화면에 여러 객체가 포함되어 있으며 MakeSense를 이용해 객체 위치를 annotation하였다. 따라서 본 프로젝트의 ‘과채류 탐지 → 개체별 신선도 분류’ 흐름에 대한 선행 연구 근거로 활용할 수 있다.

**링크**
- https://www.techscience.com/cmc/v71n3/46502/html
- https://doi.org/10.32604/cmc.2022.023357
- 폴더: `05_과채류_외관_신선도_비교_AI_서비스/03_Fruits_and_Vegetables_Freshness_논문`
- 이미지: 1개

# AgriFreshNET Freshness and Shelf-Life Image Dataset

- 원본 PDF: 과채류 외관 신선도 비교 AI 서비스
- 관련 시작 페이지: 2쪽
- 이미지: 이미지_01.png

## 내용

약 14,500장의 RGB 이미지와 24개 과채류 class로 구성되며, 실제 시장·슈퍼마켓·가정·농장·저장시설 등에서 스마트폰으로 촬영된 데이터다. 신선도 단계는 Fresh / Semi-Fresh / Rotten이며 품목별 대략적인 post-harvest shelf-life annotation도 제공한다. 데이터 형태: RGB Image + Produce Class + Freshness Stage + Approximate Shelf-life. 데이터 설명에는 개별 객체의 Bounding Box annotation이 명확히 제시되어 있지 않으므로, 여러 과채류를 동시에 탐지하는 기능에는 별도의 Detection 데이터 또는 직접 Bounding Box annotation이 필요할 수 있다.

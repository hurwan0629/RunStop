# Fruits and Vegetables Freshness Categorization Using Deep Learning

- 원본 PDF: 과채류 외관 신선도 비교 AI 서비스
- 관련 시작 페이지: 3쪽
- 이미지: 이미지_01.png

## 내용

과채류의 색(color), 질감(texture), 크기(size), 형태(shape)와 같은 외관 특징을 이용하여 신선도를 분류한 연구다. 11종의 과일·채소, 총 60,059장의 이미지를 Pure-Fresh / Medium-Fresh / Rotten 세 단계로 구분하고 VGG-16과 YOLO-v5를 적용했다. 특히 일부 이미지는 한 화면에 여러 객체가 포함되어 있으며 MakeSense를 이용해 객체 위치를 annotation하였다. 따라서 본 프로젝트의 ‘과채류 탐지 → 개체별 신선도 분류’ 흐름에 대한 선행 연구 근거로 활용할 수 있다.

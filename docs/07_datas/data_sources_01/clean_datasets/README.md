# RunStop 서울 데이터 배포판

팀원 공유용으로 정리한 최종 데이터 패키지입니다. 전부 서울로 필터링·좌표 확보가 끝난
"바로 쓸 수 있는" 데이터만 담았습니다. 원본/중간 처리 파일은 포함하지 않았습니다.

## 통합 파일 스키마 (`서울_시설데이터_통합.csv`)

`유형 / 명칭 / 위도 / 경도 / 자치구 / 주소 / 비고` — 7개 데이터셋을 한 표에서 다룰 때 사용하세요.
개별 파일은 원본 컬럼을 그대로 유지했으니, 상세 속성(예: CCTV 카메라 대수, 보안등 설치형태)이
필요하면 개별 파일을 쓰세요.

## 경사도 조회 사용법

```python
from query_elevation import get_elevation, slope_percent

get_elevation(37.5512, 126.9882)                       # 위경도 -> 고도(m)
slope_percent(37.5512, 126.9882, 37.5636, 126.9850)    # 두 지점 -> 경사(%)
```

필요 패키지: `numpy`, `pyproj`. 이 폴더 안 어디에 두고 실행해도 상대경로로 DEM 파일을
찾으니 폴더째로 복사해서 쓰면 됩니다.

## ⚠️ 반드시 알아야 할 한계 (사용 전 필독)

1. **보행자전용도로**: 원본 96건 중 절반 이상(`시간제`·`주말제`)은 **상시 차 없는 거리가
   아닙니다.** 야간 안전 스코어링에는 반드시 `보행자전용도로_전일제만.csv`(43건)를 쓰세요.
2. **보안등**: 25개 구 중 **동대문구만 데이터가 없습니다** (원본 파일 미제공). 강남·용산·
   송파·마포는 원본에 좌표가 없어 지오코딩으로 복구했고, 지오코딩 특성상 일부 누락이
   있습니다(구별 성공률은 71~96%).
3. **가로등**: 25개 구 중 **강북구만 데이터가 없습니다.**
4. **경사도 DEM**: 등고선 5m 간격을 10m 격자로 보간한 값입니다. 정확한 실측이 아니라
   보간 추정치이며, 삼각망 범위 밖 지역(전체의 약 29%, 주로 한강·경계 바깥)은 최근접
   등고선 값으로 대체했습니다.
5. **CCTV**: 강동구 일대 1,457건은 주소에 자치구명이 생략되어 있어(예: "천호동…") 자동
   구 매칭에서 빠질 수 있습니다. 좌표 자체는 정상입니다.
6. 이 데이터는 전부 **"주변에 뭐가 있는지" 스코어링용**입니다. 실제 도로망(라우팅 엔진)은
   별도로 필요하며 이 배포판에 포함되어 있지 않습니다.

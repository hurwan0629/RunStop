# RunStop 사용 데이터 인덱스

이 문서는 RunStop 프로젝트에서 현재 로컬에 확보한 데이터만 기준으로 정리한 데이터 인벤토리이다.

- 기준 기획서: `docs/01_기획/RunStop_기획안_구체화_2차.pdf`
- 실제 데이터 폴더: `docs/06_datas/data_sources/datasets`
- 공간 범위: 서울특별시 한정
- 작성 기준: 2026-08-25 현재 로컬 파일 기준

주의:
- PDF에 적힌 데이터와 실제 확보 데이터가 서로 다를 수 있다.
- 이 문서는 "받아놓은 데이터"를 기준으로 하며, PDF에 있지만 로컬 폴더에 없는 데이터는 사용 데이터로 보지 않는다.
- 전국 단위 CSV는 `시도명 = 서울특별시` 또는 주소의 서울 여부로 필터링해 사용한다.
- `전국보안등정보표준데이터.csv`는 현재 파일 안에서 서울특별시 행이 확인되지 않아 보류 데이터로 분리한다.

## 사용 우선순위

| 우선순위 | 데이터 | 이유 |
|---:|---|---|
| 1 | 무료와이파이정보, 자전거보관소정보, 스마트가로등정보, 보행자전용도로정보 | 위치 좌표 또는 도로/구간 정보가 있어 러닝 경로 추천에 직접 활용 가능 |
| 2 | 공중화장실정보 | 좌표 컬럼은 없지만 주소와 개방시간, 시설 속성이 있어 지오코딩 후 편의시설로 활용 가능 |
| 3 | 등고선 | 경사도/고도 변화 피처를 만들 수 있으나 GIS 전처리가 필요 |
| 4 | 모범음식점정보, 낚시터정보 | 러닝 경로 추천과 직접 관련성은 낮지만 주변 POI 후보로 활용 가능 |
| 주의 | 무인민원발급기 발급제증명조회 | 발급기 위치 데이터가 아니라 발급 가능 증명/메뉴 조회 데이터에 가까움. 위치 추천용으로 쓰려면 별도 발급기 위치 데이터가 필요 |

## 전처리 메모

1. CSV는 PowerShell 기준 `-Encoding Default`로 정상 헤더가 읽힌다. Python/pandas에서는 `encoding="cp949"` 또는 `encoding="euc-kr"`를 우선 시도한다.
2. 코드성 컬럼은 숫자로 변환하지 않는다. 예: `스마트가로등유형`, `초기메뉴번호`, `개방자치단체코드`.
3. Y/N 컬럼은 분석 단계에서 boolean으로 변환 가능하다.
4. 날짜/시각 컬럼은 `date`, `datetime`, `time`으로 분리 변환한다.
5. 좌표가 없는 데이터는 도로명주소/지번주소 기반 지오코딩이 필요하다.
6. 전국 단위 데이터는 서울특별시 필터링 후 별도 파생 파일로 저장하는 것이 좋다.
7. 등고선은 GIS 전처리 후 경로 후보와 공간 조인해야 한다. 먼저 CRS와 `CONT` 컬럼의 실제 단위를 설명서로 확인한다.

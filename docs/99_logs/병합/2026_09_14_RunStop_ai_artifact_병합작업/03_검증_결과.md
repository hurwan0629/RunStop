## Docker 컨테이너 상태

현재 실행 중인 routing-worker 컨테이너에서는 새 파일이 아직 보이지 않았다.

원인:

```text
docker-compose.yml의 routing-worker는 소스 볼륨 마운트가 아니라 build context 기반 이미지 실행
```

따라서 이번 변경은 routing-worker 이미지 재빌드 후 컨테이너에 반영된다.

추가 확인:

현재 컨테이너에는 다음 패키지가 없었다.

```text
sklearn: false
lightgbm: false
ai package: false
```

선택한 artifact가 실제 운영 컨테이너에서 AI ranking을 수행하려면 `scikit-learn`, `lightgbm` 의존성 반영이 필요하다. 반영 전에는 `candidate_selector.py`의 fallback에 의해 기존 `condition_score` 정렬로 동작한다.

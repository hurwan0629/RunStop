## 현재 남은 확인 항목

빌드와 컴파일은 통과했지만, 실제 데이터/외부 API가 필요한 항목은 수동 또는 통합 환경에서 추가 확인해야 한다.

```text
LOOP 추천 요청
ONE_WAY 추천 요청
ROUND_TRIP 직접 API 요청
waypoint 포함 추천 요청
maxSlope=5 fallback 여부
maxSlope=8 fallback 여부
maxSlope 없는 요청
toilet/store PREFER 응답 status
Naver 장소 검색 API
LLM route naming
running COMPLETED/STOPPED/CANCELLED 판정
```

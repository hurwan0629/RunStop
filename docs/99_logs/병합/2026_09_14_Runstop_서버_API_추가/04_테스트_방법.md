# GPT / Solapi 연동 테스트 방법

## 기본 빌드

```bash
cd backend
npm run build
```

## Mock / Console 모드

개발 기본값:

```env
LLM_MODE=mock
SMS_API_ENABLED=false
```

기대 동작:

```text
LLM은 mock adapter 사용
SMS 인증번호는 콘솔에 출력
Solapi 키 없어도 서버 시작 가능
```

확인 API:

```text
POST /api/auth/phone-verifications
POST /api/routes/recommend
```

## GPT API 모드

```env
LLM_MODE=api
LLM_API_URL=https://api.openai.com/v1/chat/completions
LLM_API_KEY=실제키
LLM_MODEL=gpt-4o-mini
```

확인 항목:

```text
prompt 있는 route recommend 요청
LLM 조건 파싱 실패 시 원래 요청으로 fallback 되는지
코스 이름 생성 실패 시 기존 이름으로 fallback 되는지
```

## Solapi SMS 모드

```env
SMS_API_ENABLED=true
SOLAPI_API_KEY=실제키
SOLAPI_API_SECRET=실제시크릿
SOLAPI_FROM_NUMBER=등록된발신번호
```

확인 항목:

```text
발신번호가 Solapi 콘솔에 사전 등록되어 있는지
수신번호가 01012345678 형태로 정규화되는지
SMS 발송 성공 후 verificationId가 반환되는지
SMS 발송 실패 시 verification record가 저장되지 않는지
```

## 실패 케이스

```text
SMS_API_ENABLED=true + SOLAPI_API_KEY 없음
  서버 시작 시 env 검증 실패

LLM_MODE=api + LLM_API_KEY 없음
  서버 시작 시 env 검증 실패

Solapi HTTP 실패
  SMS_SEND_FAILED 502

GPT HTTP 실패
  LLM_API_REQUEST_FAILED 또는 LLM_NAMING_API_REQUEST_FAILED 502
```

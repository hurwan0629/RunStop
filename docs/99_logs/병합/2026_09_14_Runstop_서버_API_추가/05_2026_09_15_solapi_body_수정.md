# Solapi 요청 Body 수정

## 원인

실제 SMS 발송 테스트에서 Solapi가 다음 validation error를 반환했다.

```json
{
  "errorCode": "ValidationError",
  "errorMessage": "[[\"messages\" 필수입니다.], \"message\" 사용할 수 없습니다.]"
}
```

## 수정

`backend/src/adapters/sms/sms.client.ts`의 요청 body를 `message` 단수 필드에서 `messages` 배열 필드로 수정했다.

```ts
{
  messages: [{
    to,
    from,
    text,
  }],
}
```

## 영향

`SMS_API_ENABLED=true`일 때 Solapi `send-many/detail` 규격에 맞는 body로 요청한다.

`SMS_API_ENABLED=false`일 때의 콘솔 출력 방식은 변경하지 않았다.

## 핵심 결정

### SMS

`SMS_API_ENABLED=false`이면 기존처럼 콘솔 출력 방식으로 인증번호를 발송한다.

```text
[SMS 인증번호] phone=01012345678, code=123456
```

`SMS_API_ENABLED=true`이면 Solapi REST API를 호출한다.

### GPT API

기존 `mock/local/api` LLM adapter 구조를 유지했다.

`LLM_MODE=api`일 때만 OpenAI Chat Completions 호환 엔드포인트를 호출한다.

### 실패 정책

```text
LLM 조건 파싱 실패:
  추천 요청 전체를 실패시키지 않고 원래 dto로 진행

LLM 코스 이름 생성 실패:
  기존 fallback 유지

SMS API 발송 실패:
  인증 요청 실패로 처리
  인증 record는 저장하지 않음
```

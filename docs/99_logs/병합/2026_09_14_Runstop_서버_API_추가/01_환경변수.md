# 서버 API 환경 변수 정리

## SMS / Solapi

```env
SMS_API_ENABLED=false
SOLAPI_API_KEY=
SOLAPI_API_SECRET=
SOLAPI_FROM_NUMBER=
```

### 동작 기준

```text
SMS_API_ENABLED=false
  Solapi 키가 없어도 서버 시작 가능
  인증번호는 콘솔에 출력

SMS_API_ENABLED=true
  SOLAPI_API_KEY 필수
  SOLAPI_API_SECRET 필수
  SOLAPI_FROM_NUMBER 필수
```

`env.ts`에서 `SMS_API_ENABLED=true`일 때 Solapi 필수 값을 검증한다.

## GPT / LLM

```env
LLM_MODE=mock
LLM_LOCAL_URL=
LLM_LOCAL_MODEL=
LLM_API_URL=https://api.openai.com/v1/chat/completions
LLM_API_KEY=
LLM_MODEL=gpt-4o-mini
```

### 동작 기준

```text
LLM_MODE=mock
  API 키 없이 mock LLM 사용

LLM_MODE=local
  기존 LocalLlmClient 사용

LLM_MODE=api
  LLM_API_URL 필수
  LLM_API_KEY 필수
  LLM_MODEL 기본값 gpt-4o-mini
```

`env.ts`에서 `LLM_MODE=api`일 때 `LLM_API_URL`, `LLM_API_KEY`를 검증한다.

프론트는 정리가 잘 되어있으며 당연스럽게도 백엔드와 맞지 않는 부분과 기술적으로 확인할 사항을 제외하고는 잘 만들어져 있는 느낌입니다. 필요시 수정할 예정입니다.

대충 볼 사항은
- OAuth를 제거할까 고민 (사용자 프로필을 받아놓기 위해)
- SMS 인증은 그대로 가기로
- 만족도를 자연어와 함께 처리하기 
- 시작 위치는 일단 사용자가 선택 가능하지만 추적 가능성 확인하기
- 즐겨찾기 추가하는 페이지 만들기
- 경유지 및 출발지/도착지 포커싱 후 즐겨찾기 누르기를 이용하여 입력해주기
- 경사도에 편차 적용하기
- 고도그래프 주려면 서버쪽 응답에 고도 넣을것 고려하기

- 구간별 러닝페이스 그래프로 보여주는 기능 추가 고려중
- 러닝 목표를 월간/주간 + 여유 되면 러닝 횟수까지

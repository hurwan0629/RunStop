# 1. 중간 프로젝트
## 각자 한 작업들
### 재빈/건희

알고리즘 탐색

- 다익스트라 알고리즘을 하면 출력에 오류가 생길 수 있다.

- 가중치를 설정했을 때 도로 A가 거리가 300m + 가로등 적음 / 비용 등이 없을 수 있음 -> 점수에 따라서 다익스트라는 사용자 요구가 A보다 다른것에 가까운 알고리즘이 있을 수 잇음

- 파이프라인 설계 기법 고려중

### 한빈/승연

- 닉네임 중복은 아님. (잘못된 표기)

- 이메일은 없애는걸로

- 프로필 이미지는 서버에서 자유 지정

- api 수요일 ~ 목요일

### 허완
- `docker` + `fatapi` + `node` + `postgis`의 프로젝트 실행 환경 및 인프라 구축
- TypeScript 등 공부하며 dto 더 깔끔하게 잡는중
- DB 업데이트 (스키마 2개짜리 단순한 마이그레이션)
